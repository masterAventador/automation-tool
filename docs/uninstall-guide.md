# 自动化运营工具 · 卸载说明

> 适用版本：0.1.0
>
> 最后更新：2026-07-26
>
> 这份说明告诉你：怎么卸载干净、卸载之后什么会留下来、留下来的东西怎么手工清掉，以及哪些东西**卸载也删不掉**。

---

## 1. 先做这三件事（重要）

在删 App 之前，请按顺序做完下面三步。跳过第一步会让平台登录状态留在本机，跳过第二步可能留下没退干净的后台进程。

### 第 1 步：退出平台登录并清理浏览器档案

打开 App → 左侧「平台状态」→ 抖音卡片 → 点「退出该平台登录并清理运营档案」。

这一步会先停掉相关任务，再把这个平台在本机保存的登录状态清掉。**直接删 App 不会自动做这件事。**

### 第 2 步：确认没有任务在跑

去「任务记录」看一眼有没有运行中的任务。有的话点「紧急停止」，等它到达终态。

**特别注意**：如果某个目标显示「结果不确定」，请先去平台核对那个动作到底发出去没有。App 删掉之后就查不到本机这边的记录了。

### 第 3 步：正常退出 App

用菜单退出，不要直接强杀进程。正常退出会把本机执行器和内置浏览器的进程一起收掉。

## 2. macOS 怎么卸载

### 卸载 App 本体

把「应用程序」文件夹里的**自动化运营工具**拖到废纸篓，然后清空废纸篓。就这一步。

安装目录里没有别的东西 —— 内置的浏览器组件、本机执行器都在这个 App 包里面，删了 App 它们就一起没了。

### 确认没有残留进程

打开「活动监视器」，搜索「自动化运营工具」。正常情况下应该一个都搜不到。如果还有，说明退出的时候没退干净，选中强制退出即可。

### 卸载之后还留在硬盘上的东西

删除 App **不会**删掉下面这个文件夹：

```
~/Library/Application Support/com.aventador.automationtool
```

（`~` 是你的用户主目录。在访达里按 `Command + Shift + G`，粘贴上面这个路径就能打开。）

里面主要有这些内容：

里面主要是这几项（左边是你在访达里能看到的名字）：

- `embedded-browser-profiles/` 和 `current-douyin-profile-v1` —— App 独立浏览器档案，也就是平台登录状态和 Cookie 存的地方（做了第 1 步的话这里已经清过了）；
- `local-executor/` —— 本机执行器的安装包、运行状态，以及它保存的脱敏诊断截图、页面结构记录和页面变化证据；
- `video-workspaces-v1/` —— 每个视频生成任务的私有目录：输入素材、中间文件、输出成片；
- `media-toolchain/` —— 视频处理用到的本机工具；
- `editing-services/` —— 视频剪辑服务的配置，阿里云访问密钥就存在这里；
- `model-service-script-v1` 和 `model-service-video-creative-v1` —— 模型服务的接口密钥；
- `device-identity-ed25519-v1` 和 `device-credential-v1` —— 本机设备私钥和设备凭据；
- `product-account-session-v1` —— 产品账号的登录会话凭据（本地版本用不到）；
- `app-updates/` —— 下载过的安装包缓存。

**要不要删？**

- **打算重装、以后还用** → 留着。留着的好处是重装之后不用重新扫码登录、不用重新填密钥；
- **彻底不用了** → 整个文件夹删掉。删之前确认一下 `video-workspaces-v1` 里有没有你还想要的成片。

删的时候直接把整个 `com.aventador.automationtool` 文件夹拖进废纸篓，然后清空。

## 3. Windows 怎么卸载

> 下面的步骤已经在真实的 Windows 安装包上走过一遍（2026-07-26）：装上、检查、卸载、再核对残留。安装包本身还没有数字签名，第一次运行时系统可能会提示来源不明。

### 卸载 App 本体

安装程序只装给当前用户，不需要管理员权限。卸载有两种方式：

1. 「设置」→「应用」→「已安装的应用」里找到「自动化运营工具」，点卸载；
2. 或者直接运行安装目录里的 `uninstall.exe`。

卸载程序会把安装目录整个清掉，包括里面自带的浏览器组件。安装记录写在当前用户名下，卸载时一并清除，不会动系统范围的设置。

实测确认过（2026-07-26）：卸载后安装目录不存在、当前用户和系统范围的安装记录都是 0 条、相关进程也是 0 个。

### 确认没有残留进程

打开任务管理器，看有没有还在跑的「自动化运营工具」相关进程。有就结束掉。

### 卸载之后还留在硬盘上的东西

卸载**不会**删掉下面这个文件夹：

```
%APPDATA%\com.aventador.automationtool
```

（在文件资源管理器地址栏直接粘贴 `%APPDATA%` 回车就能到上一级。）

内容和上面 macOS 那份清单一样，要不要删的判断标准也一样。

## 4. 卸载删不掉、需要你另外处理的东西

这一节很重要。下面这些**不在 App 的控制范围内**，删 App 一点用都没有。

### 4.1 已经发生的平台动作

**已经发出去的评论、私信和已经发布的作品，删除本产品不会把它们撤回。** 要撤回请自己去抖音、B站的后台操作。

### 4.2 平台侧的登录记录

第 1 步清掉的是**本机保存的登录状态**。平台那边的"登录设备"记录是另一回事 —— 如果你想在抖音那边也把这台设备踢掉，请到抖音 App 的账号安全设置里操作。

### 4.3 你自己导出到别处的文件

App 删不掉这些，需要你自己找：

- **诊断包** —— 你点过「导出诊断包」的话，文件在**系统下载目录**里，文件名以 `automation-tool-diagnostics-` 开头，扩展名是 `.zip`；
- **你自己另存的成片** —— 你从 App 里导出、拷贝到桌面或其它文件夹的视频。

### 4.4 云端剪辑临时上传的素材

如果你用过云端视频剪辑，素材曾经被临时上传到你选的那个地域的阿里云对象存储空间。它按保留期自动清理，但**如果你要立刻确认已经清干净，请自己登录阿里云控制台核对**。

删除本产品不会触发云端清理。

### 4.5 你在外部服务上的账号和密钥

App 里的密钥删了，不等于那个密钥失效了。如果你不打算再用了，建议：

- 去阿里百炼控制台**删除或禁用**那个接口密钥；
- 去阿里云控制台**删除或禁用**那个子账号的访问密钥。

这是最稳妥的做法 —— 密钥只要还有效，它就还有效，跟本产品装没装无关。

### 4.6 控制服务和它的数据库

**控制服务是一个独立运行的程序，不随安装包分发，也不会被卸载程序删掉。**

如果是你自己（或者部署方）在这台电脑上跑起来的，需要单独处理：

1. 停掉控制服务进程；
2. 停掉并删除它用的数据库；
3. 删掉数据库的数据目录。

任务记录、任务事件、目标信息和发布记录都在那个数据库里，不在 App 的私有数据目录里。

## 5. 怎么确认卸载干净了

按这五条挨个核对：

1. **应用不在了** —— macOS 的「应用程序」文件夹里、Windows 的已安装应用列表里都找不到「自动化运营工具」；
2. **没有残留进程** —— 活动监视器 / 任务管理器里搜不到相关进程；
3. **私有数据目录已处理** —— 上面那个 `com.aventador.automationtool` 文件夹，你要么有意留着，要么已经删掉；
4. **下载目录里的诊断包已处理** —— 搜一下 `automation-tool-diagnostics`；
5. **外部服务已处理** —— 平台登录状态、阿里百炼密钥、阿里云访问密钥、云端临时素材，按第 4 节各自处理完。

全部做完，这台电脑上就没有本产品的残留了。

---

## 6. 重装的时候会怎样

- **保留了私有数据目录** → 重装后平台登录状态、密钥配置、历史成片都还在，直接接着用；
- **删掉了私有数据目录** → 重装后相当于一台全新电脑：需要重新扫码登录、重新填密钥、重新创建剪辑项目。

产品从来没有发布过正式版本，所以**不存在"从旧版本迁移数据"这个流程**。留着的目录能直接被新版本继续使用；删掉了就是全新开始，不会有半新半旧的中间状态。
