# 自动化运营工具 · 隐私说明

> 适用版本：0.1.0
>
> 最后更新：2026-07-31
>
> 这份说明只写产品**代码里真的这么做**的事。凡是写"不上传"的地方，都是照着实际实现写的，不是承诺或者愿望。

---

## 1. 一句话总结

**你的平台浏览器登录状态、浏览器数据和诊断记录只存在你自己的电脑上；密钥长期只保存在
本机受保护存储。B站发布时，开放平台凭据会经过当前配置的控制服务短暂驻留内存，以调用
B站正式接口，但不会写入控制服务数据库或日志。**

会离开你电脑的只有下面几类东西，而且每一类你都能在界面上看到、并且可以选择不用：

1. 你主动请模型帮你写的内容（做视频时的文字、分镜，以及你明确提交的预览图）；
2. 你主动要发到外部平台的东西（视频文件、标题、简介、评论和私信内容）；
3. 你主动开启的云端剪辑要用的素材。
4. 你主动发布到 B站时所需的开放平台凭据；本地模式仍只经过本机控制服务，Demo 模式会
   通过 https 发给已签名配置指定的控制服务，并只在该次发布会话的内存中使用。

除此之外**没有任何埋点、行为统计或使用分析上报**。

## 2. 本产品在你电脑上保存什么

全部保存在 App 的私有数据目录里（具体路径见[卸载说明](uninstall-guide.md)），这个目录只有你这个系统账号能读写。

| 保存的东西 | 具体是什么 | 会不会上传 |
| --- | --- | --- |
| 平台浏览器档案 | 你扫码登录抖音之后，抖音写在浏览器里的登录状态和 Cookie | **不会** |
| 密钥 | 阿里百炼 API Key、阿里云 AccessKey、B站开放平台应用密钥与授权令牌、本机设备私钥、产品账号会话凭据 | 长期不上传；B站发布凭据会按上面的发布会话边界短暂传给当前控制服务 |
| 本机执行器数据 | App 自己管理的后台程序的状态和标识 | **不会** |
| 视频工作区 | 每个视频生成任务的私有目录：输入素材、中间文件、输出成片 | **不会**（除非你自己去发布或送去云端剪辑） |
| 诊断记录 | 脱敏后的执行器日志、页面结构变化记录、脱敏浏览器截图 | **不会**（除非你自己点导出，导出也只是存到你的下载目录） |
| 更新缓存 | 下载到一半的安装包 | 不适用 |

### 平台登录状态怎么存的

- 每个平台一个**独立的浏览器档案**，第一次运行时全新创建，路径固定但内容只在本机；
- 目录权限是私有的（macOS 上是只有你本人可读写；Windows 上使用私有的访问控制设置）；
- 同一时间只有一个进程能持有它，有原生排他锁；
- App 从来**没有发布过**，所以不存在"从旧版本迁移登录状态"这种事 —— 你的档案是全新的。

### 密钥怎么存的

密钥写在 App 私有目录下的固定文件里，由系统底层代码独占管理：

- **不进系统钥匙串**；
- **不返回给界面** —— 页面上永远只能看到"已配置"或"未配置"，保存后不回显；
- **不写进普通配置文件、日志或错误提示**；
- 内存里用完就清零。

## 3. 什么绝对不会离开你的电脑

下面这几条是产品的硬边界：

### 3.1 你日常浏览器的任何数据

产品**不读取、不复制、不导入**你平时用的 Chrome、Edge 或任何其它浏览器的档案、Cookie、书签和浏览记录。它用的是安装包自带的浏览器组件加上 App 自己新建的档案，两边完全隔离。设置页上也已经不存在"选择系统浏览器"这个入口。

### 3.2 平台登录状态和 Cookie

抖音（以及以后其它平台）的登录状态只写在本机的浏览器档案里。它不会被打包、不会被上传到本产品的服务，也不会随诊断包导出。

### 3.3 密钥不会被控制服务持久保存

阿里百炼 API Key、阿里云 AccessKey、设备私钥和产品账号会话凭据不会写入控制服务
数据库，也不会出现在日志、错误提示、诊断包和导出文件里。

B站是明确列出的例外：现有 PB-03 发布编排运行在 Control Plane 内，所以当你主动发起
B站发布时，App 会把开放平台应用密钥和授权令牌交给当前配置的控制服务。服务只在绑定
installation 与 publishJob 的短生命周期内存会话中使用它们，令牌轮换后交回本机受保护
存储，正常提交或你取消发布后立即销毁会话；若清理请求遇到通信故障，最迟在两小时硬期限
到达时销毁。数据库只保存发布摘要、阶段和平台稿件编号，不保存令牌。

### 3.4 诊断截图和诊断包

- 截图**只在任务失败时保存**；成功任务要不要留，由你在「设置与诊断」里自己开关；
- 保存的截图会把**所有文字、图片、视频、输入框内容全部隐藏**，只留下版面骨架 —— 也就是说你能看出页面长什么样，但看不到上面写了什么；
- 数量和体积有硬上限：截图最多 8 张、每张不超过 1 MB；页面结构记录最多 8 份、每份不超过 4 KB；**全部保留 7 天后自动清理**；
- 诊断包只有你点「确认导出」才会生成，最大 12 MB、最多 38 个文件，只收已经脱敏过的内容，**保存到你的系统下载目录，不上传**。

### 3.5 本机文件路径

日志、事件和错误提示里的本机路径会被抹掉。发给模型的页面内容里，本机路径和本机回环地址也会被抹掉。

## 4. 日志里会被抹掉什么

产品的日志写入前统一过一层脱敏，以下内容一律替换成 `[REDACTED]`：

- 各种凭据字段：访问凭据、刷新凭据、会话凭据、接口密钥、私钥、授权头、密码；
- Cookie 和平台会话标识（包括抖音、小红书用到的那几个具体字段名）；
- **页面正文和页面结构内容**；
- **评论正文和私信正文**；
- 请求体和响应体；
- 所有网址；
- 内嵌的数据地址；
- macOS 与 Windows 上的本机私有路径；
- 64 位十六进制的原始密钥串。

同时会清掉控制字符和会让文字显示方向反转的特殊字符，避免日志被伪造成别的样子。

这是一层基于规则的防护。它覆盖了已知的敏感字段，但不是数学意义上的保证 —— 所以产品的原则是**一开始就不把敏感内容写进日志**，脱敏是第二道闸门而不是唯一一道。

## 5. 什么会离开你的电脑（逐条说清楚）

### 5.1 模型服务（阿里百炼）

只有在你自己配置了模型服务之后才会发生。

| 用途 | 发出去的是什么 | 拿不到什么 |
| --- | --- | --- |
| 文案模型服务 | 你输入的需求文字、生成的脚本和分镜文案 | 拿不到浏览器、发布平台或视频文件的权限 |
| 视频创作模型服务 | 视频画面代码的生成与修正请求；**你明确提交的预览图** | 拿不到运营浏览器、发布平台、密钥和任意文件的权限 |

没配置模型服务时，"一句话自动制作"明确不可用 —— 产品**不会**偷偷换一个默认服务替你调。

### 5.2 智能网页操作（让模型看着页面替你操作）

首期只用在抖音作品发布这一条流程上，**没有**"输入任意网址让它随便操作"的通用入口。

发给模型之前，页面内容会被处理掉这些：

- Cookie 形式的键值对；
- 授权头和以 `sk-` 开头的密钥；
- 本机回环地址和本机调试地址；
- macOS 与 Windows 上的用户目录路径。

真实的密钥值在模型眼里永远是一个占位标记。如果某个流程真的需要把一个真实值填进页面，必须你**事先单独确认一次**，而且**只生效一次**。

模型能用的动作也被裁剪过：只剩观察、同域跳转、点击、输入、选择、滚动和受控上传。任意脚本执行、读写文件、任意下载、跨域访问和系统命令**都不可达**。

### 5.3 素材网站与配音服务（「智能素材成片」）

这一种视频制作方式会按生成出来的检索词去素材网站搜索并下载补充画面，也会调用语音合成。**检索词和要配音的文本会离开本机。** 这一点在制作方式卡片上的"数据与隐私"里就写着，选之前你就能看到。

### 5.4 云端视频剪辑（阿里云智能媒体服务）

只有在你自己配置了剪辑服务、并且提交剪辑任务时才会发生。要剪的素材会**临时上传**到你选的那个地域的对象存储空间，用完按保留期自动清理。

产品建议你用**只授予剪辑与素材暂存最小权限的子账号密钥**，产品不会用它访问你其它的云资源。

> 当前版本这条链路在界面上还提交不了，见[用户帮助](user-help.md)第 9 节。

### 5.5 发布到外部平台

- **B站**：通过官方开放接口上传视频文件，并提交标题、简介、分区、标签和封面；
- **抖音**：在可见的运营浏览器里访问抖音创作者页面 —— 这和你自己打开浏览器发作品是一回事，抖音看到的和平常一样。

发布前你会看到确认弹窗，上面写清楚发到哪个账号、哪个视频、什么标题和简介。你确认之后最多提交一次。

B站视频会在确认前先上传到平台暂存链路。开放平台凭据按第 3.3 节所述经过当前控制服务的
短生命周期内存会话；如果你使用 Demo 部署，这一步会离开本机。

### 5.6 更新检查

只有在**打包时配置了更新服务地址**的版本才会检查更新。没配置的版本完全不做这件事。

做检查时发出去的只有：当前版本号、系统平台、处理器架构。走 https，下载的安装包必须通过签名校验才会安装。

### 5.7 没有的东西

产品里**没有**任何埋点上报、行为统计、崩溃收集或使用分析服务。

## 6. 控制服务保存什么

"控制服务"是本产品的业务后端，保存任务和运行记录。

本地部署时它运行在你自己的电脑上（默认地址是本机回环地址 `127.0.0.1:8765`），数据库
也在本机。签名的 Demo 部署配置可以把它指向指定的 https 服务；此时下面的任务和发布记录
会保存在该服务端。

它保存的是：

| 类别 | 具体内容 |
| --- | --- |
| 任务定义 | 搜索关键词、动作类型、**你写的评论或私信文案模板**、目标上限、动作间隔 |
| 任务目标 | 平台上的目标编号、去重标识、**目标账号的展示名和公开账号名**、来源、判定结果 |
| 任务事件 | 每一步的进度、状态变化、脱敏后的安全描述 |
| 动作结果 | 每个目标的成功 / 失败 / 跳过 / 结果不确定，以及核对证据 |
| 发布记录 | 发布任务、内容摘要、平台返回的稿件编号、最终状态 |

**请注意这两条：**

- **你写的评论和私信文案模板是任务内容的一部分，会被保存下来。** 它不会进普通日志，但确实存在任务记录里；
- **目标账号的展示名和公开账号名会被保存。** 这两项都是平台上任何人都能看到的公开信息，产品只保存做去重、预览和结果记录必需的这两项，不保存头像、简介、粉丝数或其它个人资料。

控制服务部署到服务器上时，上面这些数据会保存在那台服务器上。平台 Cookie、浏览器档案
和原始本机证据**在任何情况下都只留在本机**，不随控制服务迁移；B站开放平台凭据只按
第 3.3 节短暂经过服务内存，不进入该表中的持久记录。

## 7. 产品替你保证不了的事

说清楚边界比说得好听重要：

- **已经发出去的收不回来。** 已经发布的作品、已经发出的评论和私信，删除本产品或者卸载它都不会把它们撤回。要撤回请去对应平台操作；
- **外部服务有它们自己的规则。** 阿里百炼、阿里云、B站、抖音怎么处理你发过去的数据，由它们各自的条款决定，本产品无法代为承诺。使用前请自己确认；
- **人工接管期间产品不记录你做了什么，但平台会。** 你在运营浏览器窗口里手动操作时，那些操作是你直接和平台发生的；
- **脱敏是规则，不是保证。** 日志脱敏覆盖了已知的敏感字段类型，但没有任何规则能穷尽一切。所以产品的第一原则是敏感内容不写进日志；
- **产品不做"防封"。** 硬频控、可见执行、预览确认和人工接管是为了让你可控，不是为了对抗平台风控。
