# 内置浏览器与视频能力安全、术语和用户品牌基线

> 机器契约：`contracts/security/embedded-browser-video-threat-model.v1.json`
>
> 用户术语：`contracts/quality/user-facing-terminology.v1.json`
>
> 静态门禁：`python3 scripts/check_user_facing_branding.py`

## 1. 总原则

- 网页、模型输出、生成 HTML、下载文件、素材元数据、上游错误和文件名全部是不可信输入。
- React 和用户输入不能提供端口、Worker 路径、浏览器路径、任意 URL、Shell 命令或本机目录。
- 任何跨进程能力都是固定动作和封闭 DTO，不提供通用代理、任意文件、任意网络或任意脚本入口。
- 用户可操作功能只有从正式 App 的正常用户入口按实际交互路径运行并核对真实最终状态，才算验收；Mock、单元测试、UI Harness、直接 API/Command 或上游 WebUI/CLI 不能代替。

## 2. 随机 loopback 端口与本机视频服务

视频制作和剪辑 Worker 在用户电脑运行，但不能成为本机或局域网公开服务：

- 只能绑定 `127.0.0.1` 或等价 IPv6 loopback，端口由系统随机分配；启动前后检查实际监听归属，不使用固定默认端口。
- Tauri 是进程树和端口的唯一所有者，通过私有启动通道传递高熵、单会话、限能力令牌；令牌不进命令行、普通环境变量、URL、React 或日志。
- 请求必须校验 Host、Origin、Content-Type、大小、超时和固定 RPC 动作；没有通用 HTTP 转发、文件服务器或跨域兼容模式。
- 每个实例使用唯一 `run_id`、任务目录和资源清单。取消、崩溃、超时、休眠和 App 退出都只清理本实例拥有的进程、端口和目录。
- 健康检查不能绕过认证；错误只返回固定代码，不回显令牌、端口所有者、内部堆栈或绝对路径。

## 3. 生成 HTML 与渲染隔离

视频创作模型生成的 HTML/JavaScript 不是可信应用代码，而是当前 RenderJob 的不可信输入：

- 只在任务私有目录和独立无头 Chromium 进程中运行，不启用 Node 集成，不连接运营 Profile、运营 CDP 或用户默认浏览器。
- 默认断网并使用本地 CSP；拦截远程脚本、字体、媒体、导航、弹窗、下载、WebSocket、外部协议和越界 `file:` 访问。
- 只允许读取 Manifest 登记的本地依赖和用户明确选择的任务素材；symlink、reparse point、hardlink、目录替换和不稳定文件身份全部拒绝。
- 帧数、时长、CPU、内存、GPU、磁盘、输出大小、单镜头和总任务都有硬上限。死循环或无限动画只能失败当前任务，不能拖垮 App 或 RPA。
- 模型只调用封闭的脚本、截图、检查和渲染工具，没有 Shell、任意文件、运营 Profile、密钥和任意网络工具。

## 4. 素材下载

所有素材下载由独立下载边界完成，模型、生成 HTML 和运营浏览器不能自行下载：

- 只允许登记 Provider 的规范 HTTPS URL；每次 DNS 解析和重定向都重新拒绝 loopback、私网、链路本地、多播、云元数据、非 HTTPS、userinfo 和跨白名单主机。
- 流式限制连接时间、总时间、响应头、文件大小和解压后大小；同时核对声明 MIME、magic bytes、允许扩展名和 SHA-256。
- 下载先进入隔离区，完成恶意内容、类型和权利检查后，才按声明文件复制到 RenderJob；部分文件、超限文件和失败缓存必须删除。
- 不携带运营 Cookie、浏览器 Header、模型密钥或产品 Session，不抓登录后页面、私有站点或用户未获授权的内容。
- `asset-rights-policy.v1.json` 默认拒绝：许可版本、取得时间、再分发、商用、人物/物权、商标或编解码器专利评审缺一项都不能进正式包。

## 5. 密钥与模型数据边界

- 百炼、其他模型、云剪辑和发布平台凭据分别存放，按任务只授予需要的最小能力；视频 Worker 不能读取全部 Provider 或平台密钥。
- 明文密钥不返回 React，不进入任务、Prompt、生成代码、Submodule、命令行、普通环境变量、文件名、日志、错误、导出和诊断包。
- 调用外部模型前必须明确告诉用户哪些文案、图片或视频会离开本机；只发送完成当前任务必需的数据。运营 Profile、Cookie、私信、联系人和无关页面内容永不发送给视频模型。
- 网页和素材中的“系统提示”“忽略规则”“读取密钥”等文字都只是不可信数据，不能扩大模型工具、网络或文件权限。
- 用 canary secret 覆盖成功、错误、取消、崩溃和诊断导出；任一边界出现 canary 即验收失败。

## 6. 路径不泄漏

- WebView、Control Plane、模型和公开任务只传稳定 UUID、内部 Provider ID 和 Artifact ID；绝对路径由 Rust 或受控本机服务从固定根解析。
- 用户选择文件后只保留授权句柄或 App 私有副本，模型不能提交目录片段。所有读写前复验规范路径、稳定 identity、权限、symlink/reparse/hardlink 和 rename 竞态。
- 清理依据 `run_id` 所有权清单，只删除当前任务创建且身份复验通过的资源，不按通配符、未解析变量或来源不明目录递归删除。
- UI、错误、事件、日志、任务名、导出和文件名不包含用户名、AppData、临时目录、原始上传路径、账号文字或上游名称。

## 7. 上游名称不进入用户界面

代码、Git submodule、内部 Adapter、SBOM 和法务声明无法也不需要隐藏上游名称；禁止的是把底层实现暴露成产品功能品牌。

用户只看到两种制作方式：

| 制作方式 | 适合 | 不适合 | 普通示例 |
| --- | --- | --- | --- |
| 智能素材成片 | 知识讲解、观点、榜单、教程、旁白字幕，以及城市、办公、做饭等补充画面 | 固定真人连续出镜、电影感剧情、精确产品动作、同一人物跨镜头一致 | 输入护肤知识，生成旁白字幕，并搭配洗脸、护肤品和生活场景 |
| 品牌动效成片 | 品牌宣传、产品发布、数据图表、产品界面、标题和代码动画 | 一句话生成逼真人物、自然运动或真实世界复杂镜头 | 输入产品更新，按品牌色生成标题、功能界面、数据和转场 |

以下位置不得出现两个上游项目名或原始 CLI/错误：菜单、路由标题、制作方式卡片、按钮、表单、帮助、加载、错误、通知、无障碍名称、任务、日志、成片文件名和导出。唯一例外是独立“第三方软件声明”法务页；该页不是功能入口，也不能用上游 Logo 或项目名作为营销标题。

内部任务和文件统一使用 `material_montage_v1`、`motion_composition_v1` 等稳定产品 ID。上游进程失败必须先映射为内部固定错误，例如“本机视频服务启动失败”，原始 stderr 只进入受限、脱敏、定长诊断，不能直达用户。

## 8. 通俗术语

用户文案不得出现没有解释的行业黑话：

| 技术词 | 用户文案 |
| --- | --- |
| B-roll | 补充画面 |
| PoC | 前期验证 |
| Provider | 制作方式 |
| Worker | 本机视频服务 |
| Artifact | 素材或成片 |
| LLM | 文案模型或视频创作模型 |
| Timeline | 剪辑时间线 |
| RenderJob | 视频生成任务 |
| Browser Use | 智能网页操作 |
| Chromium | 浏览器组件 |
| SBOM | 第三方软件清单 |

术语静态门禁扫描 App 标题、主要 React UI 源码和正式 Tauri 配置，同时扫描这些目录下的文件名。测试、内部 Provider 实现、Submodule、研究文档、源码锁和 SBOM 不属于用户界面；运行期错误、日志、任务和导出仍要在 CQ-02 从正式 App 失败路径再次验收。

## 9. 正常用户路径验收

AV-03 是安全与文案契约任务，本身不新增产品入口。后续功能必须从正式 App 正常页面依次检查导航、表单、加载、成功、失败、取消、人工接管、任务详情、日志/诊断和导出；既要证明用户只看到中文产品名称，也要核对进程、文件和平台真实最终状态。静态扫描通过只是一层门禁，不能宣称用户功能已经完成。
