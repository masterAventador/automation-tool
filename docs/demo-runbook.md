# 客户演示当天 Runbook

> 用途：演示当天拿着它照做。每一步写清**说什么、点什么、用户看到什么、要多久**，以及**这一步挂了怎么办**。
>
> 配套文件：`docs/demo-preflight-checklist.md`（演示前逐项检查）。本文件假设那份清单已经全绿——**没跑完清单就别照这份 runbook 开演。**
>
> 编写日期：2026-07-26。

## 0. 一页纸速查

| 项 | 值 |
| --- | --- |
| 演示形态 | **品牌动效成片**：一句话 → 一段 12 秒会动的 mp4 |
| 全程时长 | 约 **12–15 分钟**（含 3 分半生成等待） |
| 唯一的长等待 | 一句话生成 **约 3 分 34 秒**（开发机基线，演示机实测值见下方填空） |
| 演示机实测耗时 | ⬜ **_____ 分 _____ 秒**（彩排时填，见清单 B8） |
| 兜底素材 | 彩排时生成的那条成片，留在「视频制作 → 成片」页 |
| 出事找谁 | ⬜ **_____________**（填现场技术支持的联系方式） |

**三条铁律**

1. **不要临场改任何设置。** 演示机上的每一项配置都是前一天验过的，改了就没人知道还成不成立。
2. **不要点 §4 列出的任何禁区功能。**
3. **卡住超过 30 秒就走降级路径（§5），不要在客户面前 debug。**

## 1. 开场前 10 分钟

照 `docs/demo-preflight-checklist.md` **C 段**跑那六条（会场网络 health、App 起来、抖音登录态、磁盘、兜底成片能播、勿扰模式）。约 6 分钟。

**任何一条不过，就不要按本 runbook 的原脚本开演**，直接翻到 §5 选一条降级路径。

另外做两件 runbook 专属的准备：

- **把窗口调到合适大小**，字号够大，投屏能看清；
- **想好第一句演示词的那句「一句话描述」**，别现场憋。建议提前写好两三句备选，见 §3.2。

## 2. 演示脚本

### 幕 0 · 打开与定位（约 1 分钟）

**动作**：打开 App，停在工作台。

**说什么**（大意，不必逐字）：

> 这是一个本地运行的运营自动化工具。它装在您自己的电脑上，浏览器操作、视频渲染都在本机完成，账号和素材不上传第三方。左边这几项是它现在能做的事——今天重点看「视频制作」这一块。

**用户看到**：左侧八项导航（工作台 / 新建任务 / 任务记录 / 视频制作 / 视频剪辑 / 作品发布 / 平台状态 / 设置与诊断）。

**⚠️ 这一幕里不要点开「视频剪辑」**，理由见 §4。

**失败预案**：App 打不开或白屏 → 直接走 §5 降级路径 A。**不要在客户面前反复双击。**

---

### 幕 1 · 提交一句话（约 1 分 30 秒）

**这一幕要尽早做完，因为幕 2 的等待要靠它开始计时。**

**点击路径**：

1. 左侧「**视频制作**」
2. 「**新建视频**」标签页
3. 在「选择制作方式」里点选「**品牌动效成片**」
4. 页面上方出现「**一句话自动制作**」卡片
5. 在输入框里写一句描述（**上限 500 字**，写一句就够）
6. 点「**开始自动制作**」

**说什么**：

> 我不需要写脚本、不需要挑素材、不需要自己剪。我只要用一句话说清楚想要什么，剩下的分镜、文案、画面都由模型生成，渲染在这台电脑本地跑完。

（点下按钮后）

> 它现在开始工作了。这一步大概要三分半钟——模型要先把这句话拆成分镜和文案，然后本机一帧一帧渲染出来再合成视频。我们等它的时候，先看看别的部分。

**用户看到**：提示「已提交一句话自动制作，可到"制作任务"查看进度。」

**关键信息（要主动说，别等客户问）**：

> 这个入口生成的是**固定 12 秒**的片子。需要别的长度，用下面那个「固定模板手工制作」，段数和每段时长都能自己调。

**为什么要主动说**：界面上已经明示了这一点，客户自己会看到。**由你先说出来，是产品有边界；被客户先发现，是产品有缺陷。**

**失败预案**：

| 现象 | 现场怎么办 |
| --- | --- |
| 提示要先配置视频创作模型服务 | **不要现场配密钥。** 直接走 §5 降级路径 B（放彩排成片） |
| 「本机渲染组件暂时不可用」 | 走 §5 降级路径 B |
| 按钮点了没反应 | 等 5 秒，再点一次；仍无反应走 §5 降级路径 B |
| 描述被拒（提示要先描述） | 输入框是空的，补一句再点 |

---

### 幕 2 · 那 3 分半钟讲什么（约 3 分 30 秒）

**这是整个演示的设计难点，也是最容易翻车的地方。**

**核心思路：不要盯着进度条等。** 提交完立刻走开去讲别的，让等待变成议程的一部分，而不是一段沉默。

**推荐编排（按顺序讲，随时可被"好了"打断）**：

| 时段 | 讲什么 | 点哪里 |
| --- | --- | --- |
| 0:00–0:20 | 说明它在干什么、要多久 | 「制作任务」标签页，指一下 `准备中 / 逐帧渲染中 / 正在合成视频` 的状态流转 |
| 0:20–1:20 | **平台登录与人工接管**：这个工具用的是 App 自己的独立浏览器档案，不碰你日常用的 Chrome，也不读你的 Cookie；扫码登录一次就记住；遇到验证码、滑块、风控，它会停下来交给人，不会替你绕过 | 左侧「**平台状态**」，展示抖音「登录正常」 |
| 1:20–2:20 | **密钥都在本机**：模型密钥保存在这台电脑的受保护存储里，页面上永远不回显 | 左侧「**设置与诊断**」→ 模型服务卡片（**看，不要点「测试连接」**，见下方注意） |
| 2:20–3:10 | **任务留痕**：每个任务什么时候跑的、做了什么、结果如何都有记录 | 左侧「**任务记录**」 |
| 3:10– | 回到「视频制作 → 制作任务」，看进度收尾 | 「制作任务」标签页 |

**⚠️ 这一段有个前提必须在彩排时验掉**：**离开「视频制作」页再回来，任务还在跑、进度还在更新吗？** 见清单 D6。**如果彩排发现切走会中断，就不能用这套编排**，改成留在「制作任务」页讲解（内容照上表讲，只是不切页面）。

**其他注意**：

- **不要在这段时间点「测试连接」**。它要发真实请求，多一次网络往返就是多一个失败点，而且此刻你的注意力在讲话上。
- **不要点「安全注销」**（§4）。
- 如果客户问「怎么这么慢」——**别道歉，给数字**：

  > 三分半里大部分是模型在写分镜和文案，真正的渲染合成只占三十几秒。这台电脑没有连任何渲染农场，全部本地跑完。

**失败预案**：超过 **6 分钟**仍未完成 → 别再等了，走 §5 降级路径 B，把话接成「我们先看一条之前生成的」。

---

### 幕 3 · 成片播放（约 2 分钟）

**点击路径**：「视频制作」→「**成片**」标签页 → 找到刚才那条 → 点「**播放成片**」。

**说什么**：

> 这就是刚才那一句话生成的结果。整个过程里我没有写脚本、没有找素材、没有开剪辑软件。

**用户看到**：App 内嵌播放器播放一段 12 秒、画面在动的视频。

**可以顺带说的**：

> 生成出来的片子就在这里，可以直接进入发布流程，也可以导出后自己再加工。

**失败预案**：

| 现象 | 现场怎么办 |
| --- | --- |
| 「暂时无法读取这条成片」 | 点彩排那条成片播放（它前一天验过能播） |
| 画面自始至终不动，提示换一句描述 | 这是静图门禁拦下的。**照实说**：「它检测到画面没有变化，主动停下来了，不会给你一个假成品。」然后放彩排那条 |
| 播放器黑屏但有时长 | 换彩排那条 |

> 「画面没变化就拒绝交付」这件事，**如果发生了就大方讲出来**——一个会承认自己没做好的产品，比一个交付废片的产品更可信。

---

### 幕 4 · 发布链路（约 1 分 30 秒，**只讲不做**）

**点击路径**：左侧「**作品发布**」。

**说什么**：

> 成片可以从这里发布到平台。它的流程是：选好视频、填标题和简介，然后会**先弹出一个确认页，把要发到哪个账号、发什么内容完整列给你看**，你点确认它才真的发。这个确认步骤是不能跳过的。

**用户看到**：发布页、待发布视频卡片、标题与简介输入框、「发布到抖音」按钮。

**⛔ 到此为止。可以填标题和简介，可以点「发布到抖音」让确认卡片出现，但绝对不要点「确认发布」。** 详见 §4。

**如果客户说「那你发一个试试」**：

> 这台演示机连的是我们的测试账号，真发出去就是一条真实作品。我们不在演示里往真实平台投稿。回头在您自己的账号上，我们陪着走一次完整的。

**⚠️ 注意（写给准备演示的人，不是台词）**：产品**没有「草稿箱」这个选项**。曾经有过「发布一律走草稿箱」的约束，但它**从未实现**，代码里不存在。点了「确认发布」就是尝试真实投稿，没有安全网。见 §4。

---

### 收尾（约 1 分钟）

**说什么**：

> 今天看到的是一条完整链路：一句话进去，一个能用的视频出来，接着可以走发布。这些都在您自己的电脑上跑，账号和素材不经过第三方。

**动作**：**停在成片页或工作台，不要注销、不要关 App。** 客户可能会问着问着又要看一眼。

## 3. 演示素材建议

### 3.1 那条「一句话」怎么写

品牌动效成片产出的是**文字动效 / 数据可视化**风格，不是带实拍素材的口播视频。**描述要往这个方向写，别让客户期待错。**

**好的方向**：产品亮点罗列、数据增长说明、活动预告、要点总结。
**不好的方向**：「拍一段员工在办公室工作的画面」——这条线做不出实拍素材。

### 3.2 备选描述（提前写好，别现场憋）

- 「用蓝色商务风做一段本周销售增长说明」
- 「用品牌动效介绍新品的三个亮点」
- ⬜ 第三句：**贴合客户行业的那一句** ← **强烈建议现场化一句**，效果比通用句子好得多；**但必须在彩排时先跑通它**，别把没试过的句子留到现场。

## 4. 不要演示什么

**下面每一项都不要出现在演示里。理由写清楚了，是为了让你判断客户临场提问时怎么回。**

| 功能 | 位置 | 为什么不演 | 客户问起怎么说 |
| --- | --- | --- | --- |
| **安全注销** | 平台状态 → 抖音卡片 | **已知缺陷**：注销实际成功，界面却报失败（内层约 5 秒的轮询被包在 60 秒超时里，自己先放弃了）。**演示者会以为出错了。** 正在修 | 「注销和账号管理我们单独看，今天先聚焦生成这条线」 |
| **确认发布到抖音** | 作品发布 → 确认发布 | **会真的投稿**。产品**没有草稿箱选项**（那条约束从未实现），点下去没有安全网 | 见 §2 幕 4 的台词 |
| **视频剪辑** | 左侧导航「视频剪辑」 | 云端剪辑装配未完成，前端还走本机 `sessionStorage` 网关，页面会明说「云端剪辑服务接入后才能提交剪辑任务」 | 「剪辑是下一阶段的能力，界面先占了位」 |
| **检查更新 / 自动更新** | 设置与诊断 | 包里更新是关闭状态，内置的 feed 地址是 `.invalid` 保留域名，**点了必然失败** | 「演示包关掉了自动更新，避免演示中途弹更新」 |
| **智能素材成片** | 视频制作 → 制作方式 | 素材源 Key 未配置，上游在空列表时直接抛错；这条线一次都没走通过 | 「今天演的是本机渲染这条线，不依赖外部素材站」 |
| **背景音乐** | 制作设置 | 当前版本不提供（界面已说明）。**不要主动提起** | 客户问才答：「音乐这一块在评估」 |
| **任何需要断网恢复的演示** | — | 没有降级路径 | — |
| **第三方软件声明 / 开源软件许可** | 设置与诊断页底部 | 法定必需页，但会列出上游项目名，与产品品牌边界冲突 | 不主动打开 |

### ⛔ 演示机上绝对不要跑的东西

**不要在演示机上运行本仓库任何 `scripts/run_*_acceptance.py`**，尤其 `scripts/run_u9_06_acceptance.py`——**它会删掉整个 App 私有数据目录**，包括抖音登录态和彩排成片。

**演示机只用来演示，不用来验证。** 哪怕出于「我验证一下环境」的好意也不行。

## 5. 降级路径

**判断标准：任何一步卡住超过 30 秒，就切降级，不要在客户面前 debug。**

### 路径 A — App 起不来 / 白屏 / 闪退

**先别修。** 按顺序试：

1. 完全退出 App，重新打开（一次，只一次）；
2. 仍不行 → **改用讲解 + 现成视频文件**：把彩排那条 mp4 从访达里直接播放，讲 §2 幕 1/3 的内容；
3. 同时安排技术支持在后台查（磁盘满？数据目录权限？），**但演示继续**。

**台词**：

> 这台机器上有点环境问题，我们先看生成出来的结果，具体环节我边放边讲。

### 路径 B — 生成失败或超时

**用彩排那条成片顶上。**

**点击路径**：「视频制作」→「成片」→ 找到彩排那条 → 「播放成片」。

**台词**：

> 这条是我们之前用同样的方式生成的，流程完全一样。

**不要说**「刚才那条失败了」。也不要重新提交一次——第二次同样要三分半，而你已经用掉了预算。

### 路径 C — 会场网络不通

**这是最难受的一种，因为一句话生成需要调模型，必须联网。**

1. 先切手机热点重试（**提前把热点准备好、连过一次**）；
2. 仍不通 → 全程改为**讲解 + 播放现成成片**，跳过幕 1、幕 2；
3. 平台状态、设置页、任务记录这些**本地页面仍可正常展示**，讲解材料够用。

**台词**：

> 现场网络到我们服务的链路不太稳，生成这一步要调模型必须联网。我先把结果和流程讲清楚，回头在您那边网络环境下我们完整跑一次。

### 路径 D — 抖音登录态掉了

**不要现场扫码**（掏手机、找入口、二维码过期，全在客户面前）。

**直接跳过幕 4 的「平台状态」展示**，把幕 2 那 1 分钟改讲「任务记录」和「设置与诊断」。
