# 自动化运营工具 · 故障排查

> 适用版本：0.1.0
>
> 最后更新：2026-07-26
>
> 用法：在下面找到你屏幕上出现的那句提示，按对应的步骤做。提示文字是产品里的原话，可以直接对照。

---

## 0. 先做这三件事

大部分问题按顺序做完这三步就能定位：

1. **点一次「重新检查」或「重试」。** 很多提示是暂时性的，尤其是刚开机、刚连上网的时候；
2. **完全退出 App 再打开一次。** 注意是退出，不是关窗口；
3. **去「设置与诊断」看本机执行器的状态。** 如果它显示"已停止"，点「启动执行器」。

还不行，再往下找具体提示。

## 1. 打开 App 就进不去工作台

App 每次启动都会先检查四件事：控制服务、本机执行器、浏览器组件、App 私有数据目录。任何一项不过，就会停在诊断页上，业务功能保持关闭。

页面标题有三种，先看你是哪一种：

### 「暂时无法连接业务服务」

只有控制服务这一项没过。屏幕上写的是：

> **控制服务不可用** —— 请检查本地服务或网络；诊断不会显示连接凭据或底层异常。

怎么办：

1. 检查网络；
2. 确认控制服务在跑。**当前版本的控制服务是一个独立程序，不随安装包一起分发**，所以在一台全新的电脑上它本来就没有跑起来 —— 这是当前版本的已知限制，不是你装错了；
3. 点「重新检查」。

在这个状态下，视频制作、视频剪辑草稿、设置与诊断、开源软件许可这几块不受影响。

### 「桌面运行环境需要处理」

本机侧有问题。可能同时列出好几张卡片，逐条处理：

| 卡片标题 | 屏幕上的说明 | 你要做什么 |
| --- | --- | --- |
| 浏览器组件缺失 | 当前安装不完整，请重新安装官方客户端；无需也不要单独安装其他浏览器 | 重新装一遍 App。**不要**去装 Chrome 或 Edge，产品不用它们 |
| 浏览器组件损坏 | 组件完整性校验未通过，请重新安装官方客户端；请勿手动修改安装目录内容 | 重新装一遍。如果你或某个清理工具动过安装目录里的文件，就会出现这个 |
| 浏览器组件版本不兼容 | 组件版本与当前客户端不匹配，请下载并重新安装同一版本的官方客户端 | 别混用不同版本的安装包，重新下载同一个版本装 |
| 本地执行器不可用 | 请使用下方本地修复工具检查执行器安装包和运行状态 | 点「打开本地修复工具」，再点「启动执行器」 |
| 本地执行器动作配置缺失 | 当前安装包没有完整的动作信任配置，请安装由管理员正式配置的版本 | 你手上这个包不是完整配置过的版本，找发包的人要正式版本 |
| App 私有数据目录不可用 | 请重启 App；如果仍未恢复，请保留脱敏诊断并重新安装客户端 | 先重启 App。还不行，看看磁盘是不是满了、目录权限是不是被改过、有没有同步盘或杀毒软件在锁它 |

处理完点「重新检查」。

### 「当前安装实例已失效」

> **安装实例授权不可用** —— 此设备的演示授权已被吊销或失效，请联系演示管理员重新授权。

这台电脑的授权被撤销了。自己解决不了，联系给你授权的人。

## 2. 抖音登录相关

在「账号与平台」页里操作。

| 屏幕上的提示 | 意思 | 你要做什么 |
| --- | --- | --- |
| 请在打开的运营浏览器中扫码登录 | 二维码已经出来了 | 用手机抖音扫窗口里的码 |
| 扫码成功，请在手机抖音中确认登录 | 扫到了，等你手机确认 | 在手机上点确认，再回 App 点重新检查 |
| 二维码已过期，请重新打开登录处理 | 二维码超时 | 重新点「打开登录处理」拿新码 |
| 页面需要人工处理，请在运营浏览器中完成后重新检查 | 出现了验证码、滑块或风险提示 | **到运营浏览器窗口里自己处理**，处理完回 App 点重新检查。产品不会替你识别验证码，这是设计如此 |
| 抖音仍未登录，请在运营浏览器中继续处理 | 检查下来还是没登录 | 继续在浏览器窗口里操作 |
| 暂时无法确认页面状态，请检查运营浏览器后重试 | 页面和产品认识的不一样 | 看一眼浏览器窗口停在哪，可能是抖音改版了。手动处理后重新检查 |
| 暂时无法读取抖音登录状态，请稍后重试 | 读状态这一步本身失败了 | 稍后重试；一直这样就去「设置与诊断」看本机执行器在不在 |

### 登录状态突然失效了

正常现象，平台会主动过期登录。重新点「打开登录处理」扫一次码即可。**不用重装 App，也不用清数据。**

### 想彻底退出这个平台

平台卡片上有「安全注销」（点了会再确认一次）。它会先停掉相关任务，再清掉这个平台在本机的登录状态。清完下次要用得重新扫码。

## 3. 新建任务失败

| 屏幕上的提示 | 意思 | 你要做什么 |
| --- | --- | --- |
| 当前设备尚未授权 · 请先完成本机安装授权后再创建任务 | 这台电脑还没完成本机安装授权 | 当前版本的安装包里**没有**自助完成授权的入口，这是已知限制；需要由部署方先把控制服务和本机授权配好 |
| 任务创建失败 · 请检查业务服务连接后重试 | 控制服务连不上或返回了错误 | 参照第 1 节处理控制服务，再重试 |

| 最小间隔不能大于最大间隔 | 两个数字填反了 | 调过来 |

## 4. 任务运行中的情况

### 任务停在「等待人工处理」

产品遇到了验证码、滑块、风险提示或者不认识的页面。这是**保护机制**，不是故障。

1. 打开运营浏览器窗口，看它停在哪一页；
2. 自己把这一步处理掉；
3. 回 App 点重新检查或恢复任务。

### 某个目标显示「结果不确定」

意思是：**这个动作可能已经真的发出去了，但产品无法确认。** 常见于点了发送之后网络断了、页面卡住、或者 App 被强制结束。

**请自己去抖音看一眼那条评论或私信到底发出去没有。**

产品在这种情况下**不会自动重试**，因为重试可能导致同一个目标被评论两次或者被私信两次。这个设计不能关。

### 任务停在「已暂停」

要么是你点了暂停，要么是产品停在了一个安全检查点上。运行详情页里点「恢复」继续，或者「取消」结束。

### 想马上停下来

「紧急停止」在所有页面都能点到。它是协作式的 —— 产品会等执行器确认到达终态之后，才告诉你副作用确实停了。

如果你要的是"立刻把本机进程杀掉"，去「设置与诊断」点「本地紧急停止」。但要清楚：**它只是终止本机进程，不代表已经发出去的平台动作被撤销了。**

### 运营浏览器窗口被我关掉了

任务会检测到并进入失败或需要人工处理。重新走一遍流程即可，不会因为窗口被关就重复已经完成的动作。

### 电脑休眠之后回来任务不动了

先看运行详情页的状态。如果停在暂停或等待人工处理，按上面的方法恢复。如果状态一直不变，重启 App —— 任务快照是恢复的权威来源，已经确认完成的动作不会被重做。

## 5. 视频制作相关

| 屏幕上的提示 | 意思 | 你要做什么 |
| --- | --- | --- |
| 请先到"设置与诊断"配置并测试文案模型服务 | 没配模型 | 去「设置与诊断」→ 模型服务，配好文案模型服务并点「测试连接」 |
| 本机视频制作服务暂时无法启动，请稍后重试 | 本机的视频服务起不来 | 稍后重试；持续出现就重启 App，再看看内存和磁盘够不够 |
| 无法创建本机视频工作区，请检查磁盘空间和目录权限 | 磁盘或权限问题 | 腾出空间（智能素材成片建议留 2–6 GB，品牌动效成片 1–4 GB），并确认 App 私有数据目录能写 |
| 完整制作界面暂时无法打开，请稍后重试 | 「智能素材成片」的完整界面没起来 | 稍后重试；持续失败就重启 App |
| 制作任务状态暂时不可用，请稍后重试 | 读任务状态失败 | 稍后重试 |
| 暂时无法读取制作任务，请稍后重试 | 同上 | 同上 |
| 草稿内容或品牌素材不符合本机冻结规则，请检查后重试 | 提交的内容或上传的标志不符合校验 | 检查文字是不是空的、标志文件格式和体积是否正常 |
| 本机渲染组件暂时不可用，请到设置与诊断检查组件 | 渲染要用的本机组件有问题 | 去「设置与诊断」看本机执行器状态；还不行就重装 App |
| 品牌动效任务暂时无法提交，请稍后重试 | 提交这一步失败 | 稍后重试 |

### 视频做得很慢 / 电脑很卡

这是正常的：逐帧渲染和视频合成本来就吃处理器和内存，部分动画效果还会用显卡。制作方式卡片上标了预计耗时（30–60 秒的视频大约 3–20 分钟）和设备占用。做视频时别同时跑运营任务。

### 找不到"输入一句话自动生成"的入口

**当前版本界面上确实没有这个入口。** 「品牌动效成片」现在走的是固定模板手工制作：改主题文字、每个镜头的标题和字幕、品牌主色和辅助色、上传标志，然后提交本机渲染。

### 找不到"输入网址生成视频"

当前版本不提供这个功能，界面上没有网址输入框。

## 8. 作品发布相关

### 页面显示「暂时读不到发布状态」

**当前版本的已知限制。** 发布页面和底层之间的桥接还没有接到正式启动流程里，所以在正式 App 里这一页读不到数据。后端接口和浏览器侧的发布链路已经实现了。

页面上写的"已经提交过的发布不会因为这里读不到而重复提交"是真的 —— 读不到状态不会导致重复投稿。

### 发布结果显示「需要你到该平台核对一次」

**去平台自己看一眼作品发出去没有。** 产品在结果不明确时不会自动重发，避免同一条内容被发两次。核对完你自己决定要不要重新发布。

### 找不到快手 / 小红书 / 微信视频号

当前版本不提供这三个平台，界面上不会出现入口。

## 9. 本机执行器与诊断

| 屏幕上的提示 | 你要做什么 |
| --- | --- |
| 暂时无法读取本地执行器状态。请稍后重试 | 稍后重试；持续出现就重启 App |
| 本地执行器已停止 | 点「启动执行器」 |
| 本地执行器正在恢复 | 等一下，它在自动重启 |

「自动恢复次数」这个数字如果一直在涨，说明执行器反复崩溃。导出一份诊断包留证。

### 导出诊断包

「设置与诊断」→ 导出诊断包 → 确认导出。

- 里面只有**脱敏后的**执行器日志、页面结构变化记录和脱敏浏览器截图；
- **不含**登录凭据、完整评论或私信内容；
- **不会上传**，文件保存到你的系统下载目录；
- 最大 12 MB。

## 10. 关于浏览器的常见误解

**问：要不要装 Chrome 或 Edge？**
不要。安装包自带浏览器组件。产品**不会**去用你电脑上的 Chrome 或 Edge，装了也没用。提示"浏览器组件缺失"时正确做法是重装 App，不是装浏览器。

**问：为什么每次都弹出浏览器窗口，能不能后台跑？**
不能，这是产品的设计。浏览器窗口必须可见，你才能看到它在做什么、才能随时接管、才能自己处理验证码。

**问：它会不会动我平时用的浏览器？**
不会。产品用的是自己的浏览器档案，不读你日常浏览器的任何数据。「设置与诊断」页上也写着"不会接触你的日常浏览器档案"。

**问：为什么它不能自动过验证码？**
产品不实现任何验证码识别、指纹伪装或风控绕过。遇到就停下来交给你，这是明确的产品边界。

## 11. 还是解决不了

1. 先在「设置与诊断」里导出一份诊断包；
2. 记下你在哪个页面、点了什么、屏幕上原话是什么；
3. 记下 App 版本（「设置与诊断」里能看到）和你的操作系统版本；
4. 把这些交给支持人员。诊断包里已经做过脱敏，不含你的登录凭据和私信正文。
