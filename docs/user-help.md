> 适用版本：0.1.0
>
> 最后更新：2026-07-26
>
> 写给谁：使用本产品做日常运营的人，不需要任何技术背景
>
> 这份文档只写产品**现在真的能做到**的事。做了一半、还没验证完、或者干脆没做的能力，都会在第 2 节里明确标出来，不会含糊带过。

## 1. 这个产品是干什么的

一句话：它在你自己的电脑上打开一个**你看得见的浏览器窗口**，按你设定的规则替你做重复的运营动作；同时帮你把短视频做出来、剪出来、发出去。

它包含四块：

1. **抖音搜索曝光** —— 按关键词找到目标账号，然后只浏览、发评论，或者发主动私信；
2. **视频制作** —— 两种方式：「智能素材成片」和「品牌动效成片」；
3. **视频剪辑** —— 一个和视频制作分开的独立模块，在时间轴上整理画面、音频、字幕和转场；
4. **作品发布** —— 首期只做 B站 和抖音两个平台。

有三条原则贯穿全部功能，任何时候都不会被绕开：

- **浏览器窗口永远是可见的。** 你能看着它一步步操作，也能随时自己接管鼠标键盘。
- **遇到验证码、滑块、风险提示、异常登录，产品一律停下来交给你处理。** 产品不做识别验证码、不做指纹伪装、不做任何"绕过风控"的事。
- **每一个会真正影响外部平台的动作**（发评论、发私信、发布作品）**在提交前都必须由你亲自确认**，确认之后最多只提交一次；一旦网络断了、结果说不清楚，产品会标记成"结果待确认"让你去平台核对，**绝不自动重发**。

## 3. 安装与第一次打开

### macOS

1. 拿到 `自动化运营工具_0.1.0.dmg`，双击挂载；
2. 把里面的「自动化运营工具」拖进「应用程序」文件夹；
3. 双击打开。

安装文件约 257 MB，装到硬盘上约 565 MB —— 其中约 359 MB 是随包自带的浏览器组件。体积大是为了让你的电脑完全不用另外装浏览器。

### Windows

Windows 的正式安装包**目前还没有产出**。等它产出后，安装方式是一个只装给当前用户的安装程序，不需要管理员权限。

### 第一次打开时会看到什么

App 打开后先做一次启动检查，检查四件事：

- 控制服务能不能连上；
- 本机执行器（App 自己管理的后台程序）在不在；
- 浏览器组件完不完整；
- App 的私有数据目录能不能正常读写。

四项都正常，才会进入运营工作台。任何一项有问题，会停在一个诊断页面上，逐条列出是什么问题、该怎么办，业务功能保持关闭。具体每种提示怎么处理，见[故障排查](troubleshooting.md)。

**当前版本的一个已知限制**：控制服务是一个独立运行的程序，它**不随安装包一起分发**。所以在一台全新的电脑上，"控制服务不可用"是预期内的结果，工作台的任务数据链路暂时走不通。视频制作、视频剪辑草稿、设置和开源软件许可这几块不依赖控制服务。

## 4. 内置浏览器：第一次使用要知道的事

### 它和你平时用的浏览器是完全分开的

- App 使用的是**安装包里自带的浏览器组件**，不是你电脑上的 Chrome 或 Edge；
- 它使用**App 自己的独立浏览器档案**（保存网站登录状态的那个文件夹），第一次运行时全新创建；
- 产品**不读取、不复制、不导入**你日常浏览器里的任何数据，包括登录状态和浏览记录；
- 反过来也一样：你在 App 的运营浏览器里登录抖音，不会影响你平时用的浏览器。

### 窗口是可见的，你随时可以接管

运营浏览器不是在后台偷偷跑的。它会正常弹出窗口，你能看到每一次点击、每一次输入。任何时候你都可以直接用鼠标操作那个窗口。

### 遇到这些情况，产品会停下来

- 需要扫码或输入验证码；
- 出现滑块；
- 平台提示"异常登录"或有风险提示；
- 页面结构和产品认识的不一样。

这时候任务会暂停，界面上给出"打开浏览器处理"，等你处理完点"我已处理，重新检查"。产品不会替你识别验证码，也不会猜着乱点。

## 5. 抖音扫码登录

进入左侧「平台状态」，找到抖音那张卡片。

1. 点「打开登录处理」，App 会拉起运营浏览器窗口；
2. 用手机抖音扫描窗口里的二维码；
3. 扫码后在手机上确认；
4. 回到 App，点"重新检查"。

过程中你可能看到这些提示：

| 提示 | 意思 | 你要做什么 |
| --- | --- | --- |
| 请在打开的运营浏览器中扫码登录 | 二维码已经出来了 | 拿手机扫 |
| 扫码成功，请在手机抖音中确认登录 | 已经扫到了 | 在手机上点确认 |
| 二维码已过期，请重新打开登录处理 | 二维码超时了 | 重新点「打开登录处理」 |
| 页面需要人工处理，请在运营浏览器中完成后重新检查 | 出现了验证码、滑块或风险提示 | 到浏览器窗口里自己处理完，再回来点"重新检查" |
| 抖音仍未登录，请在运营浏览器中继续处理 | 检查下来还是没登录 | 继续在浏览器里操作 |
| 登录正常 | 好了 | 可以建任务了 |

**登录一次就够。** 登录状态保存在 App 的独立浏览器档案里，下次打开 App 还在，不用每次重扫。

需要退出时，卡片上有「退出该平台登录并清理运营档案」。它会停掉相关任务并清掉这个平台在本机的登录状态。

## 6. 新建一个抖音搜索曝光任务

当前只开放一个任务模板：**抖音搜索曝光**。

在左侧「新建任务」里填：

- **搜索关键词**（例如：新能源汽车）；
- **动作**：浏览 / 评论 / 私信，三选一；
- **评论或私信模板**（选了评论或私信时必填）。模板里只能用一个变量 `{{target_display_name}}`，它会被替换成目标账号的展示名；
- **单任务目标上限**；
- **最小间隔（秒）** 和 **最大间隔（秒）**，两次动作之间会在这个区间里随机等待。

有两个开关是**固定开启、不能关**的：

- 目标预览固定开启；
- 执行前最终确认固定开启。

### 任务创建之后

1. 产品打开运营浏览器搜索关键词，收集候选目标；
2. 你会看到一份**目标预览**：每个目标的展示名和来源，重复的、超限的会被标出来；
3. 你可以逐个排除、全部取消，或者确认执行；
4. 最终确认弹窗会同时把**动作、原始文案模板、选中目标数量**摆给你看。这份内容在弹窗打开的一刻就被冻结了 —— 如果中途目标或任务变了，旧的提交会被拒绝，要求你重新看一遍；
5. 确认后，运营浏览器开始执行，你在「任务记录」里能看到实时进度。

### 任务运行中你能做什么

「任务记录」的运行详情页里有：

- 当前状态、总进度、当前步骤、浏览器状态；
- 事件时间线；
- 每个目标的结果：跳过 / 成功 / 失败 / 结果不确定；
- **暂停**、**恢复**、**取消**、**紧急停止**；
- 需要人工处理时的接管入口。

任务的状态含义：

| 状态 | 含义 |
| --- | --- |
| 草稿 | 还没提交 |
| 校验中 | 正在检查参数和本机环境 |
| 等待平台登录 | 需要你去扫码或重新登录 |
| 等待确认 | 目标预览好了，等你确认 |
| 运行中 | 正在执行平台动作 |
| 已暂停 | 停在了一个安全检查点上 |
| 等待人工处理 | 验证码、风控、页面变化等 |
| 已完成 | 正常结束 |
| 部分完成 | 一部分目标成功，一部分失败或跳过 |
| 失败 | 无法继续 |
| 已取消 | 执行器已确认停止 |
| 结果不确定 | 动作可能已经发生，但产品无法确认 —— **请自己去平台核对，产品不会自动重试** |

## 7. 不能被放宽的安全护栏

下面这些限制写死在产品里，界面上**没有**放宽它们的开关：

- 单个任务的目标数量硬上限；
- 每个平台、每个动作的每日硬上限；
- 两次动作之间的最小间隔；
- 同一个目标 30 天内不重复触达；
- 连续失败自动熔断；
- 登录失效或出现风险提示时，立刻停止产生新的外部动作；
- 评论和主动私信执行前必须预览并确认；
- 验证码、滑块、风控只允许人工处理；
- 「紧急停止」在任何页面都能点到；
- 同一时间只允许一个任务在跑。

这不是产品做不到更快，而是**自动评论和主动私信本身就是高风险动作**。请务必先用你自己的测试账号和你有权触达的目标验证，不要拿真实客户做骚扰式测试。产品不承诺"防封"，也不承诺"完全无人值守"。

## 8. 视频制作：两种方式

进入左侧「视频制作」。页面上有七个页签：新建视频、脚本与分镜、制作设置、动效零件、预览、制作任务、成片。

第一步是在「新建视频」里**选择制作方式**。两张卡片直接告诉你各自适合什么：

### 智能素材成片

让旁白、字幕和素材画面配合起来，快速制作信息类短视频。

| | |
| --- | --- |
| 最适合 | 知识讲解、观点、榜单、教程，以及旁白配城市、办公、做饭等补充画面的内容 |
| 不适合 | 固定真人连续出镜、电影感剧情、精确产品动作，或同一人物跨镜头保持一致 |
| 举个例子 | 输入一段护肤知识，生成旁白和字幕，并配上洗脸、护肤品与生活场景画面 |
| 外部服务 | 通常需要文案模型、配音服务和素材网站 |
| 本机处理 | 素材整理、字幕排版和视频合成主要在本机完成 |
| 预计耗时 | 30–60 秒视频通常约 5–20 分钟 |
| 设备占用 | 合成时会持续占用较多处理器和内存 |
| 临时磁盘 | 建议预留 2–6 GB |
| 网络消耗 | 中到高，通常需要请求文案、配音并下载素材 |
| 数据与隐私 | 输入内容及发送给外部服务的文案、配音文本或素材检索词**会离开本机** |

选中它之后，点「打开完整制作界面」，会打开一个专门的制作界面来做这类视频。

### 品牌动效成片

用品牌配色、文字、图表和界面动画制作结构清晰的宣传视频。

| | |
| --- | --- |
| 最适合 | 品牌宣传、产品发布、数据图表、产品界面演示、标题动画和代码讲解 |
| 不适合 | 只凭一句话生成逼真人物、自然运动，或真实世界中的复杂镜头 |
| 举个例子 | 输入一次产品更新，按品牌颜色生成标题、功能界面、数据和转场动画 |
| 外部服务 | 一句话自动制作通常需要视频创作模型；固定模板手工调整时可以不调用模型 |
| 本机处理 | 画面排版、逐帧渲染和视频合成主要在本机完成 |
| 预计耗时 | 30–60 秒视频通常约 3–15 分钟，复杂动画会更久 |
| 设备占用 | 渲染时会持续占用较多处理器、内存，部分效果还会使用显卡 |
| 临时磁盘 | 建议预留 1–4 GB |
| 网络消耗 | 低到中；使用模型时需要联网，本机渲染不会上传整条视频 |
| 数据与隐私 | 使用模型时，需求和选中的品牌文字可能离开本机；本机素材不会被自动上传 |

这一种就在 App 里面编辑和预览，不用另开界面。

**当前版本的重要限制**：App 界面上的「品牌动效成片」走的是**固定模板手工制作**这条路 —— 你改主题文字、每个镜头的标题和字幕、品牌主色和辅助色、上传自己的标志，然后提交本机渲染。"输入一句话让 AI 自动写脚本、排分镜、生成动画"这条路底层已经做完，但**还没有接到界面上**，现在点不到。

### 12 套整体画面风格 vs. 134 个动效零件

这是两个不同层级的东西，别混：

- **整体画面风格**（12 套）决定**整条视频**的配色、字体、留白、组件外观和气质。例如「商务蓝」「醒目海报」「雏菊晴日」。选一套就定了整片调性；
- **动效零件**（134 个）是**插入单个分镜**的画面模块：转场、字幕特效、人名条、图表、地图、社交卡片、代码演示、3D 效果等等。

**动效零件只属于「品牌动效成片」。** 选「智能素材成片」时用不到零件 —— 那一种是用旁白配素材画面。

零件按中文分类摆好，每一项都标了性能等级、适用场景和设备要求。默认不需要你从 134 个里面挑，高级设置里才展开全部。

### 网址转视频

**当前版本不提供。** 页面上没有网址输入框，也没有抓取网页的功能。

## 9. 视频剪辑

左侧的「视频剪辑」是一个**独立于视频制作**的模块。视频制作只负责产出素材和成片，怎么剪是这里的事。

能做的：

1. 在「剪辑项目」页填项目标题和要剪的素材编号（一行一个，也可以先留空），再点「创建剪辑项目」；
2. 打开时间轴编辑 —— 三种轨道：画面轨道、音频轨道、字幕轨道；
3. 每个片段可以设时长（毫秒）、素材引用、字幕文字，以及和下一段之间的转场：无转场 / 硬切 / 淡入淡出 / 叠化 / 划像；
4. 保存修订。

**当前版本的两个重要限制：**

- **提交不了。** 点提交剪辑任务会提示「云端剪辑功能尚未开通：时间轴修订会保留在本机，接入云端剪辑服务后才能提交剪辑任务。」云端剪辑的服务端能力已经做完了，但界面还没接上去。
- **草稿关掉 App 就没了。** 剪辑项目和时间轴修订保存在当前这次打开的窗口里，**不落盘**。关闭 App 后重开是空的。重要的时间轴请自己在外面记一份。

云端剪辑首期只接阿里云智能媒体服务，需要先在「设置与诊断」里配置地域和访问密钥。

## 10. 作品发布

左侧的「作品发布」首期只开放两个平台：

- **B站** —— 走官方开放接口上传和投稿；
- **抖音** —— 在可见的运营浏览器里，由智能网页操作（让模型看着页面替你一步步操作）打开创作者发布页，识别页面并填写内容。

不管走哪条路，发布前都会把这些摆在你面前让你确认：

- 发布到哪个账号；
- 视频是哪一个；
- 标题；
- 简介。

你点「确认发布」之后**最多只提交一次**。提交完产品会去平台的作品列表独立核对结果。如果核对不出来，会显示「需要你到该平台核对一次」—— 这时候请自己去平台看一眼，**不要**指望产品自动重发。

首次发布到 B站前，请先到「设置」里的「B站发布服务」保存开放平台已签发的 Client ID、
App Secret、Access Token、Refresh Token 和有效期，并设置审批时显示的账号名称、投稿
分区、标签与转载选项。密钥只保存在本机受保护存储中，页面不会回显。未配置时 B站卡片会
显示“待配置”，不影响抖音。

**当前版本的外部验收限制：** B站 和抖音都还没有用本项目持有的真实账号完成一次真实
投稿；因此平台侧最终结果仍标为待真实凭据验收，不能把 Mock/契约测试当成真实投稿证据。

快手、小红书、微信视频号：当前版本不提供，界面上也不会出现。

## 11. 设置与诊断

左侧「设置与诊断」包含模型、视频剪辑、B站发布、本机执行器与更新等设置。

### 模型服务

当前服务商是阿里百炼。分两个用途：

- **文案模型服务** —— 用于文案、脚本和分镜。它拿不到浏览器、发布平台或视频文件的权限；
- **视频创作模型服务** —— 用于生成和修正视频画面代码，可以读取你明确提交的预览图，但拿不到运营浏览器或发布平台的权限。

两个用途可以复用同一个密钥。可选模型：DeepSeek V4 Pro、GLM 5.2、通义千问 3.7 Max（多模态版本）。

填的是阿里百炼 API Key（接口密钥）。**密钥只保存在 App 本机的受保护存储里，页面上永远只能看到"已配置 / 未配置"，保存后不会回显。** 旁边有「测试连接」，能看到剩余请求次数和剩余用量。

### 视频剪辑服务

当前服务商是阿里云智能媒体服务。需要填：

- 服务地域（北京 / 杭州 / 上海 / 深圳 / 新加坡 / 美国硅谷）；
- 阿里云 AccessKey ID 和 AccessKey Secret（访问密钥）。

**请使用只授予剪辑与素材暂存最小权限的子账号。** 产品不会用它去访问你其它的云资源。

剪辑素材会临时存放到与所选地域相同的对象存储空间，并按保留期自动清理。

### B站发布服务

这里保存 B站开放平台已经签发的应用凭据和授权令牌，以及目标账号、投稿分区、标签和
转载选项。Client ID、App Secret、Access Token、Refresh Token 与令牌有效期必须一起
填写；保存成功后密钥输入会立即清空，只回显非敏感投稿默认项。

令牌需要续期时，Control Plane 通过 B站正式刷新接口完成单次轮换，再把新令牌交回本机
受保护存储；服务端数据库不保存平台令牌。清除配置后，B站发布入口立即回到“待配置”。

### 本机执行器诊断

- 查看本机执行器的运行状态、版本、自动恢复次数；
- 启动 / 重启执行器；
- **本地紧急停止** —— 立即终止 App 管理的执行器进程树。注意：这是"把本机进程杀掉"，不是业务任务的协作式紧停，它**不代表**已经发生的外部动作被撤销了；
- **导出诊断包** —— 只包含脱敏后的执行器日志、页面结构变化记录和脱敏浏览器截图，**不包含登录凭据、完整评论或私信内容，也不会上传**，文件保存到系统下载目录；
- **保存成功任务的脱敏诊断**开关 —— 失败任务始终保存；打开这个开关后成功任务也会保存，下次启动执行器时生效。

这一页管理的是 App 自己启动的本地执行器，**不会接触你的日常浏览器档案**。

## 12. 开源软件许可

在「设置与诊断」页面拉到最下面，有一行小字「开源软件许可」，点开就是这一页。它是一个纯公示页面，不影响任何正在运行的任务。上面列出：

- 产品分发的开源组件、它们的固定版本、许可证和源码获取地址；
- 字体与素材的说明 —— 权利信息没登记齐的字体、图片、音频和视频，一律不随安装包分发。

开源许可证要求随产品一起提供这些声明，所以这一页不能去掉；它不是日常操作要用的功能，因此没有放在左侧导航里。
