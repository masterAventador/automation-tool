   转场、Material 身份、来源窗、gain、原声三态、每种轨道唯一和画面真实重叠。

## T1 RED、GREEN、代码审查与功能验收

新契约测试先写后跑，10 条中 8 条按预期失败：真实 Project/Timeline/Job 快照被旧 schema
拒绝，旧三轨枚举仍含 `audio`，output/caption style 与原声三态 schema 不存在，来源窗、音量、
真实转场重叠和六状态作业均不能通过。DTO GREEN 后，`pnpm typecheck` 又精确列出 Workbench、
local draft 测试与旧字段的全部编译漂移，证明不是只让独立 schema 测试变绿。

实现把 Project 改成 output/captionStyle，Timeline 改为 Material 身份、来源窗、gain、原声三态、
五条唯一轨道与真实 visual overlap，Job 改为六状态、单个输出 Artifact 和八个失败码。工作台草稿
同步支持旁白/原声/音乐、音量与原声处理；硬切只由 transition 缺省表达，不再保留 `cut` 别名。

逐文件 Review 找到两项缺口并各补直接 RED：文本校验只拒绝 `Cc/Cf`，会放过 Unicode 私用区
`Co`；加载现有时间轴再保存会把服务端 `trackId/clipId` 改成位置编号。现改为拒绝全部 Unicode
Other 类（字幕仅显式允许换行和制表），并让表单持有稳定领域身份；新建对象使用带 `clip-`/
`track-` 前缀的 UUID 本地 ID。复审无未关闭 finding。

最终功能验收：视频剪辑相关 Vitest `48 passed, 1 expected fail`；expected fail 是 T3 明确保留的
“生产 videoEditingGateway 尚未由真实 Tauri gateway 装配”守卫，不是 T1 回归。全量
`pnpm typecheck`、七个改动文件 ESLint、路线图计数与 `git diff --check` 全绿。T1 正式完成。
