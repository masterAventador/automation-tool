## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| submodule 未初始化或 HEAD 偏离锁定 commit | 拒绝 |
| 总数/画面块/局部组件/官方预览偏离 134/109/25/100 | 拒绝 |

## 真实边界

- 本任务只固定清单与审计事实，不下载远程依赖、不本地化字体、不替换素材——那是 BM-12/BM-13 的范围；
  127 项标 `needs_localization*`、70 项标 `*asset_replacement`（含重叠）在替换完成前不得进入发行包。
- Roadmap 6.6 的实扫概述写“约 31MB、127 项含运行时远程引用”；对锁定 commit 仅按
  registry-item.json 声明的安装文件做确定性重扫的结果是约 28.7MB、125 项（把 demo.html 等
  非安装文件计入会得到 132 项）。台账以可复算的 125/28.7MB 口径为准，不修改 Roadmap 叙述。
- 远程包许可（含 GSAP Standard License、es-atlas 未验证）为离线登记的假定值，BM-12 本地化时必须
  逐包核验许可证文本；示例素材再分发权一律登记为 `unverified`，默认拒绝随包分发。
- 商标指示词是确定性关键词扫描，未覆盖纯图形内容（如 X Logo 矢量、示例头像肖像）；
  这些由素材种类维度兜底（凡捆绑 image/audio/model_3d/font/vector 即要求替换）。
- 本 worktree 的两个 submodule 从主仓库既有 module 对象库离线检出到锁定 commit，未访问网络；
  `check_third_party_sources.py` 验证 gitlink、tag、origin 与工作树干净。
