## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| 上游测试写输出 | 只写 `.local/vendor-tests` 隔离树 |
| 真实 vendor 有 tracked/untracked 改动 | 起跑前或收尾门禁拒绝 |
| vendor clean 但 HEAD 错 | revision 门禁拒绝 |
| 隔离树受全局 LFS clean filter 影响 | 用本地对象/物化策略避免把真实内容误判脏 |
| Windows 无 clonefile | archive fallback 产生真实目录，不造软链 |
| 测试失败 | 仍执行真实 vendor 收尾复验 |
