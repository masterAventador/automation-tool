`workbench.spec.ts` 的“工作台已挂载”在 37 ms 内恒真。原提交保留受控桌面测试 Adapter，
随后直接加载生产 `main.tsx`，使启动门禁和生产组合根真正参与测试。

## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| 入口重新注入无条件 ready | Node 生产入口契约拒绝 |
| 入口绕过 `main.tsx` | 导入关系门禁拒绝 |
| 测试 Adapter 缺生产 gateway | 生产组合根负责完整注入 |

| 生产入口真的存在回归 | 桌面 spec 会真实变红，不再由桩遮蔽 |

## 真实边界

该任务的完成定义是“测试不撒谎”，不是“工作台在所有环境已可用”。观察到真实隐藏 Tauri
停在启动门禁是正确 GREEN：它证明恒真桩已消失。正向业务闭环仍须由准备完整环境的各专用
桌面验收证明。
