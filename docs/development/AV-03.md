## 失败矩阵

- Worker 绑定固定/非 loopback 端口、令牌缺失/重放、跨 Session 连接或退出残留：威胁模型要求拒绝。
- 生成 HTML 尝试联网、越界文件、弹窗/下载、运营 Profile/CDP、无限动画或资源耗尽：拒绝并只失败当前任务。
- 素材 URL 命中私网/元数据、重定向换域、DNS 重绑定、超限、MIME 欺骗或权利缺失：拒绝。
- 密钥进入 React、Prompt、任务、命令行、普通环境、日志、错误或导出：验收失败。
- 绝对路径、symlink/reparse/hardlink、rename 竞态或跨 `run_id` 清理：拒绝。
- 上游项目名、`B-roll`、`PoC` 出现在正式 UI 源码或文件名：静态门禁失败；原始 Worker 错误直达用户同样失败。
- 文件超限、非 UTF-8 或用户界面扫描目录被 symlink 替换：门禁失败，不能借此绕过扫描。
