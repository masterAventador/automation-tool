## 失败矩阵

- 可执行路径不存在、非文件、无执行位：计划构造即拒绝，不触碰 Browser Use；
- 已用过（非空）的 Profile 目录：拒绝，防止污染或复用运营数据；
- 非 loopback / localhost 别名 / 0.0.0.0 / 外部 IP / https / ws / 带路径的
  CDP 地址：拒绝；
- 未知计划类型：拒绝；
- Cloud 凭据出现在环境中：启动环境剥离；云同步与遥测强制关闭；
- CDP Chromium 提前退出、随机端口超时：探针显式失败并清理进程。
