    `StartupGate.tsx` 安全修复提示改为组件语义中文文案（重装官方客户端，明确
    "无需也不要单独安装其他浏览器"）；Gateway/types 严格校验新词汇，未知值仍
    protocol_mismatch 拒绝。

## 失败矩阵

- 组件缺失/损坏/版本不兼容三态分别产生独立诊断码与独立中文修复提示；
- 未知快照值、缺键、多键、错误类型在 Gateway 与 startup 投影双层拒绝
  （protocol_mismatch），不静默降级；
- 本地环境查询失败时前端按最保守组合（executor_unavailable +
  browser_component_missing + app_data_unavailable）封锁工作台；
- 诊断文案不含路径、组件内部名或上游品牌（branding 扫描通过）；
- 版本漂移在发行物解析层即被独立分类，不会被当作可重试的一般损坏。
- 缺失组件不能通过选择系统 Chrome/Edge 修复；真实 App 打开修复工具后无浏览器
  选择面板，重新检查仍 fail closed。
