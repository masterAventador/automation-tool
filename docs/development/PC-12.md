## 2. 排除的四类，每类都举实物

**假界面布景**（4 个）：`macos-tahoe-liquid-glass` 75 个节点是 Finder / File / Edit
这类菜单栏，`ios26-liquid-glass` 54 个是 iOS 应用名，`vfx-liquid-background` 49 个是
虚构持仓行情，`liquid-glass-widgets` 是温度／电量／步数。

**假终端输出**（12 个 `code-snippet-apple-terminal-*`）：`bash — 80×24`、
`Last login: Mon Jun`、`drwxr-xr-x 8 user`、`CONTAINER ID IMAGE`。
与假 macOS 桌面同一类——**真正会变的那部分在脚本里逐行打字**，这正是它们被判为
「混合型」的原因。

**上游自我宣传**（1 个）：`vfx-iphone-device` 是上游自己的网站装在手机框里
（`Made with 动效画布`、`Log in`），与第一批排除的 `vfx-magnetic` 同一类。

**不可寻址的碎片**（3 个）：`blue-sweater-intro-video` 把文字按字母拆开做动画
（`Intro | ducin | g`）；`apple-money-count` 唯一的可见节点是计数器起始值 `$0`，
**脚本一启动就覆盖它——替换它什么都不会发生**，这是「混合型」最会骗人的形态；
`vfx-text-cursor` 打字机效果把整句拆碎并混入空节点。

## 3. 第五类是量出来的：`morph-text`

它五句文案轮播，语义上完全是可替换文案，第一眼该收。

但像素预算探针在**六个采样时刻量到的宽度全是 0**——五句从不同时布局。
给它开槽就得配一个编出来的预算，而预算是 PC-14 判溢出的唯一依据。
**本轮排除**，等槽位分组能表达「轮播的一组」时再收。

**这条只有量过才知道**，读源码看不出来。

## 4. 署名要按前缀排除，不能精确匹配

第一版把 `Source: U.S. Census Bureau` 写进精确匹配表，而发布树里是
`Source: U.S. Census Bureau, 2024`——带年份，漏掉了。改为前缀匹配
（`Source:` / `Fuente:` / `©`）。用前缀而不是子串：那一行必须**以**署名开头，
否则一个碰巧提到出处的标题会被一起排除。

## 5. 界面家具也补进固定文本表

`Search` / `All` / `Favorites` / `Recent`（筛选标签）、`Reply` / `Mark Read` / `Share`
（按钮）、`r/`（被切开的前缀碎片，紧跟其后的 `r/xxx` 才是可寻址的那个）。

反过来，`reddit-post` 与 `x-post` 的点赞数、时间戳**保留为槽**——上游自己的占位文案就
写着「Prompt to change this body text, the subreddit, username, and vote count」，
是它明示要人改的。

## 7. 探针因此改进了一处

原本只在时间轴末帧量一次。轮播型零件在末帧只有一句可见，其余为 0。
改为在六个位置各量一次、每槽取最宽的那次读数——**一个槽在它自己被显示的那一刻才有
真实预算**。溢出状态仍取稳定帧那次，因为溢出是稳定帧的属性而不是最宽帧的。

`morph-text` 即使这样仍全 0，所以它被排除而不是被凑一个数。

## 9. 收口（2026-07-29）：第二批真的被用上了

§8 说「产品入口尚未用到第二批」。PC-10 于 2026-07-29 在真实 App 用户路径上出的
成片，第 6 镜选中的 `data-chart` 就是第二批的：

```
contracts/video/motion-part-usability.v1.json
  data-chart → copyLocation: "mixed", batch: "second"
```

**这一镜同时验到了第二批的设计判断本身是对的。** 第二批的规则是「只给 DOM 那部分
开槽，脚本那部分标为不可替换」，成片里看到的正是这个：

| 画面元素 | 在哪 | 结果 |
| --- | --- | --- |
| 标题「增长趋势」 | DOM，槽 17 | 换成中文 ✅ |
| 副标题「连续四周保持两位数增长」 | DOM，槽 19 | 换成中文 ✅ |
| 图例「第1周」「第2周」 | DOM，槽 24 / 29 | 换成中文 ✅ |
| 坐标轴 `Jan`…`Jun`、`$8K`…`$22K` | 脚本运行时生成 | **保持英文，这是对的** |

最后一行是判据而不是缺陷：把 `data-chart` 分为 `mixed` 的意思就是「这部分动不了」，
所以中英并存恰好是分级判对了的样子。要让坐标轴也中文化是另一件事（得改脚本，
属于零件源码，`vendor/` 只读），不在本任务范围。

抽帧命令与逐槽核对见 `PC-03.md` §14。
