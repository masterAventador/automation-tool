## 失败矩阵

- 未知平台、未知机制、非枚举字符串平台/机制构造 `PublishCapability` 一律拒绝。
- deferred 平台标记启用、deferred 平台换成 `official_api`/`browser_use`、启用平台
  换机制、启用平台标记停用或降为 deferred，全部构造失败。
- deferred 平台无法构造任何 `PublishJob`（三种机制全被拒绝），领域层不存在入口。
- 非法状态转换拒绝：`dispatching` 只可从 `approved` 进入；审批前状态不可直接进入
  `outcome_uncertain`；五个终态不接受任何后续转移；非枚举值走状态机接口一律拒绝。
- `PublishJob` 事实一致性拒绝：`failure_code` 只与 `failed` 共存、封面与视频
  Artifact 相同、SHA-256 非法、标题/简介为空白、超长或含控制字符、revision 非法、
  非 UTC 时间与时间倒退全部拒绝。
- 契约 JSON 与领域冻结表逐平台、逐机制、逐启用位对照，任一漂移即测试失败。
