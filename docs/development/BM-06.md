## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| 契约公开风格少于或多于 12 套 | 适配层抛错，构建与测试失败 |
| 契约或装配输入含重复风格标识 | 拒绝 |
| 内部专用 code-editorial 混入公开清单 | 拒绝 |
| 展示层补充信息缺一套、多一套或挂到未知标识 | 拒绝 |
| 中文名为空、重复或直接等于英文标识 | 拒绝 |
| 未选择制作方式或选择智能素材成片 | 不出现风格选择器，设置页保持原语义 |
| 键盘焦点在首尾继续移动 | 循环到另一端，不丢焦点 |
| 重复选择与切换选择 | 始终只有一项 `aria-checked="true"` |
| 页面出现上游项目名或英文内部标识 | 组件测试与桌面验收扫描均失败 |

## 正常用户路径验收

验收构建使用生产 `main.tsx` 和正式 `WorkbenchShell`，复用 VF-06 隐藏隔离 App、隔离
identifier 与动态空闲 WebDriver 端口。用户路径为：

1. App 正常进入“RPA 运营工作台”，点击左侧“视频制作”；
2. 直接打开“制作设置”，确认显示“尚未选择制作方式”，没有风格选择器；
3. 回到“新建视频”选择“品牌动效成片”，再进入“制作设置”；
4. 确认 12 张风格卡片逐一展示契约中文名、示意预览、适用场景和风格标签，初始全部未选中；
5. 鼠标选中第一套，核对“已选择风格”提示；按右方向键加回车切换到第二套，核对前一项取消、
   仅一项选中；
6. 整页扫描确认没有上游项目名和英文内部风格标识。

该路径操作的是正式 App 左侧入口和生产组件，最终状态由真实 DOM 可访问属性与页面文本确认，
不是网页预览、Mock 或测试专用入口。

## 真实边界

- BM-06 只交付风格目录、中文选择与页面内选中状态；不创建 ContentBrief、不持久化选择、不做
  风格推荐、品牌覆盖或冻结（BM-07），也不启动渲染浏览器或生成预览视频（BM-03/BM-16）。

  渲染链路接入后提供，页面文案已如实说明。
- 适用场景与风格标签是产品展示层信息，风格身份与中文名的唯一事实源仍是 BM-01 契约。
