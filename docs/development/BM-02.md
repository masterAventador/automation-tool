## 交付范围

- 固定官方 Node.js 22.23.1 运行时和三种桌面发行归档摘要，候选包包含自己的
  `runtime/node` 与 `app/worker.mjs`，不从 PATH、用户目录或全局安装发现 Node。
- `VideoWorkerLaunch::bundled_node` 只接受无链接的完整包目录，使用绝对运行时与绝对入口参数，
  清空子进程环境后交给既有 `LocalVideoOrchestrator` 管理。
- Node Worker 对齐现有 1.0 协议：随机 loopback、每次启动随机令牌、HMAC 版本握手、认证健康检查、
  UUID v4 取消确认、EOF 正常退出和固定错误文案。
- 本任务只建立命令行/SDK 适配器进程边界，不启动 Chromium、不暴露 WebUI、不生成视频；后续
  BM-03～BM-05 才分别接渲染浏览器、安全沙箱与 AI 编排。

## 失败矩阵

- Node 版本、官方归档摘要、Worker/协议版本或包目录漂移：构建或启动拒绝。
- 包目录、运行时或入口为相对路径、符号链接、重解析点、缺失文件或不可执行文件：Tauri 拒绝。
- bootstrap 多字段/少字段、版本/类型错误、WebUI/模型越权、非绝对素材目录或令牌格式错误：固定
  退出码 65，错误不回显令牌、路径或输入正文。
- 健康请求缺令牌、路径/方法错误：只返回 401；ready/health/cancel 证明不匹配时 Rust 拒绝。
- 取消只接受规范 UUID v4 和有效 HMAC；错误命令被忽略，不产生伪造完成事件。
- stdin 关闭后监听端口关闭；App stop/drop 继续使用既有进程树清理，避免孤儿 Worker。
