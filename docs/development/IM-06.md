## 失败矩阵

- document-start 阶段还没有 `<body>`：保持启动隐藏状态，等待 DOM 建立，不提前误判失败。
- 真实表单的稳定容器、主题输入或生成按钮在 60 秒冷启动门限内没有同时出现：进入封闭错误页。
- 可见文本或 `aria-label`、`aria-description`、`title`、`alt`、`placeholder` 中仍有上游名称：进入封闭错误页。
- 外链无法解析或清洗后仍能跨来源跳转：进入封闭错误页；Tauri 同时继续拒绝新窗口和下载。
- Streamlit 动态重绘标题、页首、任务文字或设置弹窗：顶层 DOM 观察器再次清洗；对子 iframe 不重复注入，避免组件递归。
- 新手引导和弹层：只隐藏并移出可访问树，不删除 React 根或上游组件节点，避免框架反复重建。
- 封闭处理：使用独立固定遮罩，不替换 Streamlit 的 `<body>` 或 React 根，失败页不会反过来导致 WebView 崩溃。

## 正常用户路径验收

验收构建使用正式 `main.tsx`、WorkbenchShell、Tauri Command、受保护子 WebView 和 671 MB 的真实冻结 Python 服务候选。
唯一测试辅助是桌面驱动和无效测试 API Key；没有替换业务页面或伪造 Streamlit 表单。用户路径为：

1. 正常启动 App，进入“设置与诊断”，保存文案模型服务测试配置；
2. 点击左侧“视频制作”，选择“智能素材成片”，点击“打开完整制作界面”；

4. 确认真实“视频文案”和“生成视频”表单可见，页面文本没有上游名称，DOM 没有可跳转外链；
5. 确认产品字体主题生效，点击“制作服务设置”；
6. 确认“素材 API”和 Pexels 配置可见，“大模型设置”不可见；
