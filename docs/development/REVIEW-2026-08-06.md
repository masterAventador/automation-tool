## 第一部分：SA 自愈式自动化（SA-01～SA-07）

### SA#1（严重 95）外部副作用已发出，接管决策却判成「可以继续」——会重复投稿 → [T7]

`backend/src/automation_tool/executor/skill_replayer.py:134`（配合 `:113` 初始化、`:156` 置真），消费点 `skill_handback.py:41`。

`dispatched` 在每一步循环开头被重置为 False，而它要表达的风险是整轮的。实跑（3 步技能，第 2 步外部「发布」，第 3 步确认框后置条件失败）：发布已点，决策却是 `resume_browser_use / may_continue=True / remaining=[1,2,3]`——remaining 里还列着那个外部发布步。「发布→关确认弹窗」正是最常见的真实形态。SA-05 docstring 与 SA-05.md 的承诺在此形态下均不成立。

修法：`dispatched` 改成运行级单调标志（一旦置真不再回落），或复用既有 `SideEffectState`（见 SA#6）。

### SA#2（严重 92）管理投影统计与停用按 version 单键，多技能互相串台 → [T8]

`skill_management.py:56`、`:58`、`:85`。`stats: dict[int, VersionStats]` 与 `disabled: set[int]` 只以版本号为键，而 `build_management_view` 自己按 `skill_id` 分组。实跑：A 技能的成功率原样安到 B 技能头上，停用 A 的 v1 把 B 的 v1 一起停掉；`applicableVersionFor` 走同一份 stats，路由跟着错。键应为 `(skill_id, version)`。

### SA#3（重要 88）成功率 0% 的旧版本永远压过新编译候选，自愈闭不了环 → [T9]

`skill_router.py:79-83`。排序元组第一位是「有没有历史记录」，`(1, 0.0, …) > (0, 0.0, …)` 恒成立。实跑：0 成功/500 失败的 v1 永远压过无历史的 v2，v2 永远拿不到第一次机会。至少应让明显失败的版本（rate 低于阈值或连续失败 N 次）让位给未验证版本。

### SA#4（重要 90）press_key 的键、scroll 的方向从来没传给页面适配层 → [T10]

`skill_replayer.py:153`，协议定义 `:51`。`ReplayPage.act(kind, handle, value)` 的 value 仅在 fill 时非空；契约支持 press_key（Enter/Escape/Tab/ArrowDown/ArrowUp）和 scroll（up/down），清洗器照实产出，回放时全丢。接上真实浏览器会静默做错事而不是报错。SA-04 失败矩阵没覆盖这里。

## 第二部分：视频制作与构建修复

### C1（严重）headless montage 观察桥安装必然抛异常——素材成片整条静默不可用 → [T2]

`workers/material_montage/montage_runtime.py:187` 装桥，`job_observation_bridge.py:48` 的 `ObservedTaskState.__init__` 要求 `runtime_root/storage/tasks` 已存在（`resolve(strict=True)`）。全仓唯一创建它的 `_prepare_private_project()`（`webui_runtime.py:375`）montage 路径从不调用——`start_montage` 只调 `_preload_private_config`（只写 config.toml 和注入 app 模块）。`resource/` 同样没准备（上游 `resource_dir()` 是字幕字体解析根）。

用户点「开始制作」→ worker 起来 → montage 线程第一步 `FileNotFoundError` → 线程死 →（叠加 C2）exit 0 → 任务永不落终态、界面只有「已提交制作任务」。

测试没抓到：唯一相关用例 `test_start_montage_drives_the_upstream_pipeline_under_the_bridge` 同时 mock `_preload_private_config` 并传 `pipeline=fake_pipeline`，而装桥在 `upstream_engine()` 里——传了 pipeline 就走不到。测试名里的 "under_the_bridge" 是它唯一没验的东西。

修法：装桥前建 `storage/tasks`，`resource/` 准备从 `_prepare_private_project` 拆出两边共用；补一条不传 pipeline、真执行 `upstream_engine()` 的用例。

### C2（严重）montage 线程无异常处理，看门狗无条件 `os._exit(0)` → [T3]

`montage_runtime.py:190-213` run() 全程无 try；`worker_main.py:310-321` `_exit_after_montage` join 后一律 `os._exit(0)`，注释「观察桥已原子落终态」是假设不是保证。覆盖面：C1 的 FileNotFoundError、冻结环境导入失败、Pexels 401、断网、ffmpeg 失败——全部以成功收场。修法：run() 包 `try/except BaseException` 写失败终态并记录原因；看门狗按线程结果选退出码。

### C3（严重）归档摘要校验同义反复，机器级缓存不复检——契约 `archive_sha256` 在发版路径从未生效 → [T4]
