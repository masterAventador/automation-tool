## 失败矩阵

- 旧根存在任意内容：不读取、不迁移、不删除，新根独立创建（专项测试）；
- 根/子目录 DACL 不合规、NTFS junction/reparse 组件、普通文件替换目录、缺失
  Profile：Windows 原生 fail-closed 用例在新根下全量通过；
- 重复加锁、显式释放、进程内与真实子进程排他、锁持有进程被强杀：
  `browser_profile_locks` 8 个 Windows 用例通过；
- Windows 首轮 RED 发现 `.removing-<uuid>` 被普通安全名称校验误拒，导致安全删除和
  crash tombstone 恢复失败；现在仅为内部 tombstone 开放精确前缀，其他点号名称继续
  拒绝；
- Windows 首轮 RED 还证明普通锁文件句柄允许 rename/delete replacement，且持锁删除
  目录违反 Windows 句柄语义；现在普通运行锁拒绝 delete sharing，删除锁在关闭句柄前
  留下持久 active fence，rename 后只由恢复型删除锁清除，活动 lease 删除返回
  `ProfileInUse`，锁文件替换失败；
- 原目录与 tombstone 同时存在时先按身份/reparse 边界确认冲突、再校验单一路径 DACL，
  稳定返回 `RecoveryRequired`，不删除任一目录；
- 指针文件损坏/指向不存在 Profile：既有用例覆盖（重建全新 Profile）。

## 正常用户路径验收

不适用于独立用户操作：本任务交付的是 Rust 内部存储/锁/删除契约，没有单独页面或
按钮。生产入口 `current_douyin_profile` 已验证首次创建与 App Store 重开后的稳定路径
复用；真实抖音扫码 Cookie 写入、登录状态探测和正式 App 重启复用属于 EB-11 的产品
纵向验收，不是 EB-09 的未完成项。
