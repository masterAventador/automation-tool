## 失败矩阵

- `.gitmodules` 缺失、多出未登记 submodule、出现 branch 或 origin 漂移：拒绝。
- 父仓库 Gitlink、submodule HEAD、正式 tag 或 annotated tag object 漂移：拒绝。
- submodule 内出现修改或未跟踪文件：拒绝，不能把上游源码修改混入发行物。
- LICENSE 缺失、SPDX 或文件摘要变化：拒绝并要求重新评审。
- 未登记字体、素材、音乐、音效、地图、3D、生成资产或编解码器：默认拒绝发行。
- 源码 SBOM 格式、组件数、版本、commit 或许可证与锁不一致：拒绝。
- 严重安全公告命中且没有已修复版本或外围缓解：关闭对应功能并阻止发布。
