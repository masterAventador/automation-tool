## 失败矩阵

- submodule 未初始化、源码路径为符号链接或嵌套 submodule 未递归初始化：拒绝。
- origin、正式 tag、完整 commit 或 Git tree 任一漂移：拒绝。
- tracked 文件被修改、出现未跟踪补丁或嵌套 submodule 脏污：拒绝。
- 输出位于上游目录、输出已存在或输出目录不存在：拒绝，不能覆盖或污染源码。
- 归档出现绝对/越界路径、链接、文件数漂移、关键入口缺失或 SHA-256 不符：删除失败输出并拒绝。
- 合同允许联网、补丁、脏树、写入源码或运行时升级时：静态策略检查拒绝。
