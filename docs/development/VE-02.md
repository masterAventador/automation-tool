## 交付范围

- 领域层新增 `backend/src/automation_tool/control_plane/domain/video_editing_provider.py`：
  `VideoEditingProvider` 端口只暴露 `capabilities` / `validate` / `submit` / `get` /
  `cancel` / `fetch_artifacts` 六个方法，输入输出全部是领域对象或供应商无关值对象。
- 统一封闭错误分类 `EditingProviderErrorCode`（invalid_input / unsupported_capability /
  not_found / conflict / dependency_unavailable / provider_error），`EditingProviderFailure`
  只能携带该枚举与逐码固定安全文案，构造时不接受任何自由文本，供应商原始错误不可能进入领域层消息。
- 任务状态统一映射：`EditingProviderJobSnapshot` 只使用 VE-01 的 `EditingJobStatus` 与
  `EditingFailureCode`，成功必须有输出、失败必须有失败码、其余状态两者皆空，与 `EditingJob`
  事实约束一致；快照字段经精确字段断言，恰好为 provider_id、editing_job_id、status、
  failure_code、output_artifact_ids 五个供应商无关字段。
- 幂等键：`EditingIdempotencyKey` 复用既有 Executor 协议幂等键的受限字符集与 128 长度上限，
  `editing_submission_idempotency_key` 从 `EditingJobId` 派生规范键，`EditingSubmission`
  构造即校验键与任务身份一致，重复提交语义封闭可测。
- `VideoEditingProviderRegistry`：按稳定 `EditingProviderId`（封闭小写标识格式）显式注册/解析；
  重复注册报 conflict、未知 ID 报 not_found、裸字符串或非法 ID、不满足端口结构的对象一律
  fail closed；公开表面仅 register / resolve / registered_provider_ids，无运行时动态发现。
- 一致性测试套件 `VideoEditingProviderContract`：对任意 Provider 实现跑同一套行为测试
  （幂等重放返回原结果、同键不同内容 conflict、协作式取消、取消与完成竞争保持终态、
  fetch_artifacts 仅认可已确认成功、错误分类封闭、供应商字段精确不泄漏），并由测试用
  `FakeEditingProvider` 全量通过，证明未来接阿里云/腾讯云 Adapter 不需要改领域层。
- 不包含阿里云实现、HTTP/SDK 调用、数据库迁移、API 路由与 UI；这些分别属于 VE-03～VE-07。

## 失败矩阵

- 供应商 DTO 泄漏：快照与能力对象为 frozen+slots 精确字段数据类，测试逐一断言
  vendor_job_id / region / api_key / access_key / secret / endpoint / raw_response 等
  供应商字段不存在，且实例必须是精确领域类型，Adapter 子类无法夹带字段。
- 能力不支持却静默降级：`validate` 与 `submit` 对未声明轨道/转场/时长/轨道数一律抛
  unsupported_capability，契约测试断言拒绝且不产生任何任务副作用。
- 重复请求与幂等：同一 `EditingSubmission` 重放返回原结果、不产生第二个任务；同键不同
  Timeline 修订报 conflict；幂等键与任务身份不一致在构造期直接拒绝。
- 取消与完成竞争：取消是协作式的，非终态只允许收敛到 cancelling 或合法终态；已成功任务
  被取消时保持 SUCCEEDED 与既有输出，不会被改写。
- 非法状态汇报：快照状态只能是 `EditingJobStatus`，事实约束（成功有输出、失败有失败码）
  违反即构造失败；契约测试还断言相邻快照状态满足 VE-01 状态机合法转换。
- 未知资源与非法标识：未知任务 get/cancel/fetch_artifacts 报 not_found；注册表未知 ID 报
  not_found、重复注册报 conflict、裸字符串与不满足端口的对象 fail closed。
- 错误分类不封闭：`EditingProviderFailure` 拒绝枚举外取值（含同值字符串与外部枚举），
  消息为逐码固定文案，测试断言全集恰好六个码。
- 结果获取越权：fetch_artifacts 在任务未确认成功时报 conflict，防止把未确认结果当成品导入。
