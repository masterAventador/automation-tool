安全性质做成每步而非每轮：

- **语义锚点执行、不每步调视觉模型**：`ReplayPage` 协议只有 `find(role,name)` /
  `holds(condition)` / `act` / `current_path`，全是语义/条件，无坐标——这正是回放
  便宜可复现的原因，视觉模型只在失败后 SA-05 交回 Browser Use 时才回到画面；
- **参数预检在任何副作用之前**：缺 fill 参数 → 页面一次未被触碰即失败，而不是点了
  一半在不可逆点击之后才发现（测试断言 `page.side_effects == []`）；
- **一步一副作用**：每步只执行它那一个动作；
- **外部边界属于 skill 不属于 page**：回放器数自己将执行的 external 动作，超过
  `sideEffectBoundary` 立即停；
- **独立验收**：每步后置条件在下一步前校验，「点了但没达成」是失败不是静默通过；
- **检查点定位交接**：失败 `ReplayFailed.checkpoint_index` 报最近检查点，供 SA-05 从
  安全点恢复。
