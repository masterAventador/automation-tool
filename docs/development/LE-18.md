## T1 RED 目标

1. 已登记映射可被幂等忘记；重启后仍不存在，其他素材映射不受影响。
2. 忘记映射只改私有注册表，绝不删除、改名或读取用户原文件。
3. 原子写失败时磁盘文档与当前进程内存都保留旧映射，不能出现“本进程忘了、重启又回来”。
4. 非规范 UUID 与运行中被放宽/替换的 state 目录继续 fail closed，错误和 traceback 不含路径。

## T5 GREEN、代码审查与功能验收

GREEN 复用冻结 Python Worker 既有的 `127.0.0.1` 网关，为每次 Worker 会话从随机 session token
按独立 HMAC domain 派生 256-bit 预览 capability；ready 事件单独签名该 capability，Rust 严格验证后
才可生成 `/api/v1/material-previews/{capability}/{materialId}`。Tauri command 只接收 Material ID，
WebView 看不到 Worker bearer、源路径或文件名；Worker 重启会自然轮换 capability。

Worker 内部新增不透明预览 lease：每次请求重新加载私有注册表，resolve 后用独立二进制 descriptor
打开，比较设备/inode/mtime/大小/类型/权限，读取前后继续 fstat；映射在打开过程中重定位也会在返回
前复核并拒绝。MIME 是 ffprobe 的封闭素材 kind 与文件 magic 的交集，不信扩展名；首次安全探测按
Material ID + 文件身份缓存，串行抑制并发探针且 LRU 上限 2048。HTTP 支持完整 GET/HEAD 和一个
规范 `bytes=start-end`、open-ended 或 suffix Range；精确返回 200/206/416、`Content-Range`、
`Accept-Ranges` 和 `no-store`，多 Range、超长/非 ASCII Range、错误 Host、外部 Origin、query、
未知 capability/UUID 与请求体全部 fail closed。流式读取每 64 KiB 复核 descriptor，变化时截断连接。

逐文件 Review 找到并关闭六项真实问题：预览 Host 初版未严格限定本机地址；重复 Range 的 416
缺少 `Content-Range: bytes */size`；内容类型缓存会并发重复 ffprobe 且未设上限；映射在 probe 与
descriptor 打开之间重定位时可能返回旧文件；`open` 后 fstat 失败和 provider close 异常分别可能
泄漏 descriptor/逃到 HTTP traceback；冻结包 cold probe 漏导入新预览模块。最终复核 capability
domain separation、ready HMAC、Range 算术、MIME 闭集、Windows 二进制读取、Tauri feature gate、
删除后失效和所有异常链，无未关闭 finding。
