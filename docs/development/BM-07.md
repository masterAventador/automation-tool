## 失败矩阵

| 边界 | 结果 |
| --- | --- |
| 锁定源少/多/重复/内部风格混入，版本、提交、路径或摘要漂移 | 加载契约即拒绝 |
| `frame.md` 缺 frontmatter、必需字段、颜色或字体 | 拒绝，不写 RenderJob |
| 超 512 KB、NUL、远程/file/data/javascript、主动 HTML、网络/进程调用 | 拒绝 |
| `url(...)` 绝对、`..`、反斜线、缺失、符号链接或越出 workspace | 拒绝 |
| 品牌色格式错，或声明品牌色/字体但最终 frame 未实际应用 | 拒绝 |
| 字体 family/file 不成对、扩展名或魔数错 | 拒绝 |
| Logo 非 PNG/JPEG/WebP、扩展名/魔数错、超限 | 拒绝 |
| RenderJob 根非真实空目录 | 拒绝，避免覆盖既有任务 |

| 品牌输入含 CSS/URL、Logo 文件名穿越 | 前端草稿拒绝，冻结层再次拒绝 |

## 正常用户路径验收

`run_bm_07_acceptance.py` 复用 VF-06/BM-06 的独立 identifier、隐藏正式 Tauri App 和动态
WebDriver 端口；构建使用生产 `main.tsx`、`WorkbenchShell`、`VideoStudio` 和
`MotionStyleCatalog`，没有用 React Mock 页面代替。用户路径为：

1. 从正式 App 左侧进入“视频制作”，打开“制作设置”，确认未选制作方式时没有风格 UI；
2. 回到“新建视频”选择“品牌动效成片”，再次打开“制作设置”；
3. 首屏只出现 3 套中文推荐且逐项显示“推荐”；
4. 输入“本周销售增长 38%”及真实正文、品牌主色、辅助色和字体；
5. 把合法 PNG 字节作为真实 `File` 交给生产文件输入控件，生产 `FileReader` 读取后确认
   实际内容预览里有 `<img alt="品牌 Logo 预览">`、Logo 文件名、字体与真实文案；
6. 点击“查看全部 12 套风格”，逐项核对契约中文名、实际内容预览、场景和标签；
7. 鼠标选择第一套，方向键 + 回车选择第二套，确认始终仅一项 `aria-checked=true`；
8. 扫描页面确认没有上游品牌名、内部英文风格标识或未公开风格。

这条路径真实启动 Tauri App 并操作生产 DOM；单元测试不作为正常用户路径替代。

## 真实边界

- macOS WebKit WebDriver 无 `uploadFile`，不能自动操作原生文件选择器；当前桌面验收在正式
  App WebView 内创建含合法 PNG 字节的真实 `File/FileList` 并触发生产 `change`，验证了业务
  输入、`FileReader` 和真实 `<img>` 预览，但不声称覆盖操作系统文件选择器。
- 页面当前保存的是编辑草稿；把选择、品牌文件和冻结摘要从 App 提交到真实 RenderJob 的纵向
  命令属于 BM-08。BM-07 已证明同一生产输入经锁定 builder/freezer 可重现，但尚未声称 App
  点击即完成冻结。
- 本任务不生成视频文件，因此没有“打开成片看字幕/Logo”的媒体验收可做。BM-08/BM-16 一旦
  产出真实视频，验收必须抽取首/中/尾与声明字幕、Logo、转场的关键帧做视觉检查，不能只看
  文件存在、状态或元数据。
