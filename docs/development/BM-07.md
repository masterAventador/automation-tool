| --- | --- |
| 锁定源少/多/重复/内部风格混入，版本、提交、路径或摘要漂移 | 加载契约即拒绝 |

## 真实边界

- Windows 正式包已覆盖普通本地绝对 NTFS 路径。生产协议只把浏览器读取后的文件名和字节传给
  Rust，不传源路径，因此不宣称用原生文件框覆盖 reparse point、路径大小写或 8.3 短路径；
  这些路径字符串矩阵不属于本次“选择本地品牌文件并冻结字节”的功能闭环。
- WOFF/TTF/OTF 与 JPEG/WebP 的支持由扩展名、魔数、大小和请求边界确定性测试覆盖；正式包
  纵向样本使用 WOFF2 + PNG，不把未实际操作的格式写成真人验收。
- 正式包 runner 唯一非零项是现有安装包大小上限：实际 NSIS 为 `450,691,975 bytes`。安装、
  启动和 BM-07 用户路径均成功，该阈值更新属于 BM-16 包体任务，不扩进 BM-07。
