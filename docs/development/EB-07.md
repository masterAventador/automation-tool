## 失败矩阵

- 发行物缺失 → `ComponentMissing`（映射 `browser_component_missing`）；
- 发行物被篡改/校验失败 → `ComponentInvalid`（映射 `browser_component_invalid`）；
- 缓存后可执行文件被删除/替换为非可执行 → 下次解析检出并重新全量验证/报错；
- 缓存后 resource/发行物根或可执行路径组件被 NTFS junction/reparse 替换 → 缓存
  复查失败，重新全量验证并拒绝；
- Authority 锁不可用 → `Unavailable`（映射 `storage_unavailable`）；
- 命令链路无系统浏览器发现调用点（生产实现签名不再接收浏览器设置服务）；
- Debug/错误码不泄漏安装路径。
