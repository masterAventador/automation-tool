## 一、方法

判据按任务要求分三档，每条都标明自己属于哪一档：

1. **能实测的实测**——跑命令、挂载镜像、跑 Playwright，把真实输出贴进清单（这是清单原本的写法，跟随它）；
2. **只能读源码确定的**（界面文案的字面值、契约的取值集合），读源码但在文档里标明证据层级；
3. **本机验不了的**（真实签名包的目视、Gatekeeper 同意框、会场网络、Windows），**明确写「只能在演示机上验」并写出具体动作**，不含糊地写「确认一切正常」。

有意避免了一种做法：**用读代码去推断布局**。本项目 07-26 已有两条这样的推断被实测证伪（一条说两个页签塌了其实没塌，一条说某个定高是防跳动其实不是）。所以凡涉及「这一页放不放得下、这个表单多宽、这个折叠默认开不开」，一律跑 Playwright 实测，不看 CSS 猜。
