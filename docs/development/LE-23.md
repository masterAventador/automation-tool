# LE-23 Windows 正式包纵向验收

状态：本地正式包阶段已完成，待真实模型纵向验收

用户可操作：是

## 边界与拆分

本任务只在 Windows 正式安装包上独立复验 LE-22 已定义的原声成片用户链路，不新增视频
业务功能。验收必须从 current-user NSIS 的全新安装目录启动 App，经正式页面导入一条真实
人声视频、生成草稿并出片，再交叉核对 PostgreSQL、Timeline、Job、Artifact、ffprobe 与
原声音频包络；另外从安装目录重新核对随包 FFmpeg、VAD/ASR 运行时和中文字体。

1. T1：固定 Windows NSIS 正式页面旅程、已安装资源和证据编排契约；
2. T2：复用生产 Windows release assembly，构建、安装、运行并卸载隔离 NSIS；
3. T3：Windows 真机真实模型纵向执行、Code Review、专项/必要全量门禁与路线图收口。

## 当前约束

真实旅程会把受控人声音频、抽帧和固定提示词发送给外部模型；当前尚无该外发授权。
PyInstaller、生产资源装配、NSIS、current-user 安装和卸载已经在 Windows 真机执行完成，
但该主机没有 Authenticode 发布身份，且没有调用外部模型；这些未完成证据不会由 debug
自动化壳、未安装目录或分层测试替代。

### TDD 与实现

RED 先要求 Windows runner、独立 Tauri/WebDriver 配置和固定 `pnpm` 入口；首轮因 runner
不存在而失败。Green 后复用 LE-22 的正式页面旅程、数据库证据和原声音频判据，同时复用

runner 安装到唯一 LocalAppData 产品目录后，重新核对内置浏览器、FFmpeg、视频 Worker、
VAD/ASR 能力探针、134 项动效和中文字体清单，再用随包 FFmpeg 制造受控人声视频。App 从
正式设置、素材库、剪辑项目、智能剪辑、时间轴和提交页面完成原声成片；随后核对唯一

注册表和三个隔离端口，证据摘要不记录私有路径或模型密钥。

### Windows 真机包功能验收

SSH 默认令牌是提升态，runner 的 current-user 安全门禁按预期拒绝。没有放宽门禁，而是用
Windows 任务计划程序在当前已登录用户的 `Medium Mandatory Level`/`LIMITED` 令牌下启动
同一脚本。正式构建装入真实 Executor、锁定 Chromium、三项视频运行时和 134 项动效目录，
再由 Tauri 生成 NSIS 并静默安装到唯一 LocalAppData 产品目录。

`cjk` 字段，而生产 `motion-part-typography.v1.json` 使用 `chineseFace`。先把测试夹具改成
真实契约键并复现失败，再最小修正审计器；PC-16 与 motion catalog release 专项
`16 passed`，复审没有剩余 finding。修复提交后重新生成同 revision 安装器，安装目录回读
