## 官方回调机制联网核实（2026-07-23）

用无头浏览器读取官方文档正文核实，B站开放平台存在官方 Webhook 消息推送：
HTTPS POST 到控制台配置的回调地址，`verify_webhooks` 握手回显 `data`，签名头
`x-bilibili-signature` = SHA1(app_secret + request_body)，5 秒连接超时、失败重试
至多推送 3 次（开发者需去重）；与投稿状态相关的事件为 `video_open`（state 0）与
`video_fail`（state -2）。来源已登记进契约 `sources`：

- 消息推送概述：https://open.bilibili.com/doc/4/b369a652-0e26-8ddb-74f0-20c74234fcd6
- 投稿开放浏览消息（video_open）：https://open.bilibili.com/doc/4/5f4b3ac2-a6b8-cc32-f13b-48e548f5a8ce
- 投稿失败消息（video_fail，PB-02 已登记）：https://open.bilibili.com/doc/4/bec4b752-37e3-0049-3a23-e85143d21797

本地单机部署没有公网入站地址，无法接收推送，因此轮询查询是第一实现；本任务只

  审核中，不猜测语义；fixture 中的 -30 只是"非 0/-2"占位；
