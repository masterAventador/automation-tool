### 第三轮修复：Important 80 补的守护本身是假的——继承自 `video_creation.py` 的既有缺陷

**问题**：

```python
banned_fragments = {"provider", "model", "vendor", "api_key", "base_url", "voice_id"}

`set.intersection` 是**整元素相等**匹配，不是子串匹配。变量名叫
`banned_fragments`（**片段**），操作却按整词比较：

>>> {"provider"}.intersection({"provider_job_id"})
set()          # 不拦
```

`provider_job_id`、`vendor_id`、`api_key_ref`、`model_name`、`base_url_override`
