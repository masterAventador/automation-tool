## 交付范围

新增 `backend/src/automation_tool/executor/browser_use_safety.py`，三道 Browser Use
安全门禁（页面输入一律不可信）：

- **不可信输入脱敏** `redact_untrusted_text`：DOM 文本、截图提取文字、导航指令、
  Agent 历史进模型前，脱去 Cookie 名值对、`Bearer`/`sk-` 密钥、CDP/loopback
  地址、`/Users`·`/home`·`C:\Users` 本机路径；普通中文页面文本原样保留；幂等。
- **敏感数据占位门禁** `SensitiveDataGate`：模型只见 `<secret>key</secret>` 占位
  （对齐 Browser Use 0.13.6 的 sensitive_data 机制）；未登记占位符、真实密钥值
  混入模型文本一律拒绝；把真实值透给页面需**事先确认且单次消费**。
- **外部副作用临界点确认** `SideEffectConfirmationGate`：发布/评论/私信 dispatch
  前 `present` 展示目标账号 + 内容摘要供用户确认，`authorize_dispatch(confirmed=True)`
  换发**单次** dispatch 令牌，`consume_dispatch` 只对**确认时的同一 content_hash**
  放行一次——真实浏览器动作因此只可能对用户批准过的内容发生一次。
- 令牌常量时间比较，不进 `repr`/summary/日志；ActionGate/ledger 复用见「真实边界」。
