## 正常用户路径验收

验收构建使用生产 `main.tsx` 和正式 `WorkbenchShell`。测试 bootstrap 只加载桌面驱动，隐藏
App 的启动环境被设为已就绪以满足本任务前置条件，不提供视频数据。用户路径为：

1. App 正常进入“RPA 运营工作台”；
2. 点击左侧“视频制作”；
3. 标题变为“视频制作”，默认打开“新建视频”；
4. 确认创建按钮禁用且页面明确不会生成演示任务；
5. 依次点击“脚本与分镜、制作设置、预览、制作任务、成片”；
6. 每页核对真实空状态，并扫描整个页面没有上游名称或假结果。

这条验收点击的是正式 App 正常左侧入口，不是单元测试、浏览器网页、直接组件调用或测试专用
业务页面。启动前置条件不参与视频页面最终状态判定。
