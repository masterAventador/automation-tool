- 恢复边界：每日加密备份、保留 7 天，`RPO <= 24h`、`RTO <= 4h`；客户 Demo 前必须恢复到新的隔离 PostgreSQL 实例，不能覆盖原 primary 冒充演练
- Secret 边界：DB URL、账号 Pepper/fingerprint key、运维 capability digest、动作授权私钥和 TLS 私钥不得进入 Git、镜像、部署清单、argv、日志或 WebView
- 后续归属：C10-02～C10-07 分别落地镜像、数据库、HTTPS、Secret、账号和 App Profile；C10-08～C10-12 只有获得部署授权后才产生云端事实；C10-13 固化最终手册
