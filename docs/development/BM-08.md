## 失败矩阵

- 输入拒绝（Rust 单测）：活动内容、URL/脚本类输入、缺段/超长分镜、非法颜色、非
  PNG/JPEG/WebP Logo 在创建工作区前失败；
- 非法状态转换：对终态任务取消返回 `job_unavailable`；快照/推进拒绝非法迁移；
- 取消与正在发生的渲染竞争：真实验收首次提交在“逐帧渲染中 55%”取消，Rust 立即写
  权威 cancelled checkpoint（进度封顶 99），Worker 在帧边界观察 marker 后协作退出
  并返回 `render_cancelled`，不再产出帧；
- 单 Worker 多请求竞争：取消后 Worker 退出前的第二次提交返回 `render_unavailable`，
  App 显示可理解文案，重试后受理（真实验收覆盖）；
- 渲染/编码失败路径：`render_sandbox` 失败映射 RenderFailed/EncodingFailed 并保留
  失败 checkpoint（sandbox 8 项矩阵覆盖预算杀进程组、协议失败、帧清理）；
- Artifact 删除语义：导入成功后删除工作副本，删除失败回滚已导入 Artifact（Rust 单测
  `artifact_import_removes_the_working_copy_and_user_delete_removes_the_only_video`）；
- 资源与泄漏：验收后复查进程树无 Chromium/Worker/FFmpeg 残留，帧临时文件全清理。

- 隐藏测试窗口内 WebKit 不派发动画帧：antd 弹层入场/离场动画永不完成，

  限定并按存在点击。此边界仅影响隐藏窗口自动化，不影响正常可见产品；
- Apple silicon 真实渲染约 2 秒完成，任何依赖“渲染足够慢”的取消验收都不成立；
  验收用浏览器启动延迟包装制造确定性取消窗口，产品代码无测试专用分支；

  `Emulation.setDeviceMetricsOverride` 显式钉死（本次真实成片 640×232 暴露）；

- WebDriver 无法走 macOS 原生文件选择器，Logo 以真实 PNG 字节构造 `File` 交给生产

  BM-07 验收，不作为 BM-08 的完成条件；
- Windows 已由 BM-08 自己在无测试 feature 的生产 NSIS 已安装可见 App 中重跑手工
