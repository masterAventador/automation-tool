## 失败矩阵

- Python Playwright 声明不是精确版本，或与 `uv.lock`/契约不一致：拒绝。
- Node 测试工具使用范围版本，或与 `pnpm-lock.yaml`/契约不一致：拒绝。
- 已安装 Playwright 的 `browsers.json` 摘要、Chromium 完整版本、修订号、标题或默认安装标记漂移：拒绝。
- 组件候选的 Playwright 版本或 Chromium 任一字段不一致：拒绝。
- 目标不是 macOS arm64、macOS x86_64 或 Windows x86_64，或 ID、系统、架构组合不完全相同：拒绝。
- Schema、策略、必需字段、字段类型或未知字段不符合契约：拒绝。
- 合法 macOS/Windows 组件清单：接受。
