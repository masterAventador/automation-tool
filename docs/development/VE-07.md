## 真实云端纵向验收（2026-07-23，cn-beijing）

按既有授权用真实凭据走完整生产链路（非直调下层函数）：

1. ffmpeg 生成 2 秒 128×128 输入 → 真实 OSS PutObject 到 `editing-staging/v1/<digest>.mp4`；
2. 生产 `AliyunImsEditingProvider.submit` 真实提交（ACS3-HMAC-SHA256），得
   **JobId=`00fd1914-c0c9-4687-96e3-5ca7a1957426`**；
3. 生产 `AliyunImsEditingReconciler.reconcile_until_terminal` 携带真实 VE-07 导入器
   （替换 VE-06 最小 Registrar）真实轮询收敛 **SUCCEEDED**；
4. 导入器从 `editing-output/v1/<job>.mp4` 真实流式下载 **36547 字节**成片，
   SHA-256=`b3d7de3ba00ffce3178289fbb6b35ce669e01d296f15a48292069ec91e7790f9`，本地复读
   文件校验一致；谱系记录输入 Artifact、Timeline 修订、provider `aliyun_ims`、契约核对
   日期与费用 **0.015 CNY（up_to_480p × 1 计费分钟，estimated）**；
5. 幂等重入：第二次 `register_confirmed_output` 返回相同 Artifact，OSS 流式调用计数保持 1；
6. 清理器按 `succeeded_imported` 删除 staging 输入与云端输出对象，逐 key 签名 HEAD 复核
   404，`verified_absent=True`；safety-net 再删为幂等空操作。

本次验收费用：1 个计费分钟（≈0.015 CNY）+ 少量 OSS 请求；无云端常驻资源残留。

## 失败矩阵

- 幂等/重复：台账命中直接返回既有 Artifact，零下载；并发保存冲突经读回收敛；相同谱系
  重放为空操作，不同谱系冲突拒绝且原记录不动（内存与 PostgreSQL 两个实现均有测试）。
- 下载异常：对象缺失、空对象、超出大小上限 → `provider_error`；传输失败 →
  `dependency_unavailable`；全部路径不落台账、Sink 无残片。
- 意图/基准缺失：未知或 PREPARED 意图 → `not_found`；谱系基准缺失 → `not_found`，
  不登记任何输出。
- 本地落盘：中断流留下零文件（tmp 清理）；重复 Artifact 文件拒绝且原内容不变；封闭
  媒体类型之外拒绝。
- 清理策略：`outcome_uncertain` 一律保留（证据不销毁）；删除失败列入 retained 且
  `verified_absent=False`；项目前缀之外的 key 拒绝删除，防误删。
- 持久层：第二个 video 行、kind-媒体类型错配、费用总额被篡改分别被
  `ux_editing_output_artifacts_one_video`、`ck_editing_output_artifacts_media`、
  `ck_editing_output_lineages_cost_total` 拒绝；重启后新连接读回一致（进程重启测试）。
