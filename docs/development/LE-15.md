   任一漂移均 fail closed。

### 结构化分句与边界

1. 模型正文只接受一个严格 JSON 对象，顶层精确为 `sentences`，值为有序字符串数组；
   重复 key、未知字段、数组为空、非字符串元素、首尾空白和不安全控制字符均拒绝。
   `sequence` 由本地按数组顺序生成 `1..N`，不让模型自报序号。
2. 用户文案最多 4,000 字符；最多产出 128 句，单句最多 1,000 字符且总脚本文本最多
   4,000 字符。单句上限必须直接复用既有
   `motion_authoring.voiceover.MAX_NARRATION_CHARS`，保证 T1 产物天然可被 T2 的唯一
   TTS 实现消费，不建立第二个旁白长度常量。
3. 模型回复体、结构化正文、请求 ID、token 和超时均有硬上限；只接受
   `finish_reason=stop` 且无非空 refusal 的第一条回复。超时、拒答、截断、空正文、
   畸形 JSON 或任何边界漂移都转换为无异常链的固定
   `ScriptSegmentationRejected("script segmentation request rejected")`，不回显上游正文、
   请求 ID、密钥或本机路径，不自动重试。
4. T1 的完成证据是供应商无关协议、目录选择、默认/开启 thinking、封闭请求与有序结果的
   聚焦自动化；没有用户入口，因此最多是分层证据。真实模型、TTS、PostgreSQL 与正式包
   在 T4 模块收口时统一验收，不在每个小任务重复跑全量。

   `ScriptRecordingRejected("script recording rejected")` 均不携带本机路径。
2. 录音不复制进 Authoring Workspace，也不覆盖 T2 的 `voiceover/sentence-NNNN.wav`。
   T3 只产出同一源录音上的逐句 `source_start_ms/source_end_ms` 与实测差值；后续渲染按
   这些真实边界裁切原录音。上传文件的持久化、MaterialPathRegistry 身份和前端选择器归
   LE-18/LE-19，本子任务不偷建第二套路径登记。
3. 本地音轨抽取复用 LE-14 已验证的单声道 16 kHz PCM、有界 FFmpeg、稳定 inode、
   0700 临时目录和 best-effort 清理实现，不跨模块导入其私有 helper。已知是用户旁白，
   因此不套用 LE-14 用来排除“背景路人声”的 5 秒/30% 主体证据门槛；但仍必须由同一
   Silero VAD 找到真实人声区间，无人声或本地处理失败一律 fail closed。

### LE-14 ASR 复用面

1. 只复用 LE-14 的供应商无关 `SpeechTranscriptionAdapter` 和
   `SpeechAudioBatch`，以及既有 `qwen3-asr-flash-2026-02-10` Adapter；ASR 仍只能看到
   有界规范 WAV bytes 与时长，看不到上传路径、原文件 bytes、公开 URL、脚本或
   Workspace。
2. 既有 OpenAI-compatible ASR 只返回整段文本，不返回时间戳；官方文档明确只有异步
   `qwen3-asr-flash-filetrans` 才提供句/字级时间戳。因此 T3 不伪造“按字符比例切到某个
   毫秒”的云端时间戳，也不新增第二个 ASR 模型、异步任务或 OSS 上传面。录音仍按
   LE-14 的 180 秒 / 6 MiB 上限惰性分批，任一批失败、空文本或累计超限即整次拒绝。

### 句子对齐算法

1. 对齐前把脚本各句和 ASR 全文做 NFKC + casefold，只保留 Unicode
   Letter/Mark/Number；空规范文本拒绝。全文与逐句均计算 Levenshtein 距离：规范长度
   不超过 4 必须完全一致，其余错误量不得超过较长文本的 15%。ASR 全文以顺序动态规划
   搜索连续、非空且完整覆盖全文的逐句分区，每个候选片段长度先受同一 15% 门槛约束；
   每段除满足本句门槛外，还不得同样或更接近另一条不同脚本句子，也不得完整取自另一条
   不同脚本句子。固定字符比例不能用：前句出现允许的漏字时会把后句首字符错误划给前句。
   这只容忍标点、空白、大小写、ITN 与少量识别误差，不允许漏句、增句或调换顺序。
2. 时间边界只从 Silero VAD 的真实有序人声区间中选择。人声区间少于脚本句数时，在首次
   ASR 前拒绝，要求用户在句间留下可检测停顿；区间足够时按各句规范字符数对应的累计
   人声时长目标，贪心选择最近且仍给后续每句至少保留一个区间的真实区间边界。每句可
   合并多个相邻人声区间，内部停顿保留；绝不在一个连续人声区间内部猜毫秒切点。
3. 结果逐句携带原 `ScriptSentence`、真实 `source_start_ms/source_end_ms` 和二者差值，
   严格连续 sequence、有序不重叠、全部落在 ffprobe 实测录音时长内；结果另带路径无关
   的完整识别文本并在 `repr` 中隐藏。任一结构漂移统一固定拒绝，不返回部分对齐。
