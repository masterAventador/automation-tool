1. 消费方只依赖 `ScriptSegmentationAdapter` 以及供应商无关的 Options、Reply、Sentence

   顶层 `models`，且声明 `text=true`。provider、API mode、HTTPS Base URL、用途和模型
   任一漂移均 fail closed。
3. `enable_thinking` 是供应商无关的请求级布尔配置，默认精确为 `false`；百炼请求体每次
   都显式发送该布尔值，不按模型名推断、不省略。LE-24 后续只传入总开关值，不改

4. 模型只收到用户文案和固定结构化输出指令；不携带素材路径、输出目录、视频、音频、

### 结构化分句与边界

1. 模型正文只接受一个严格 JSON 对象，顶层精确为 `sentences`，值为有序字符串数组；
   重复 key、未知字段、数组为空、非字符串元素、首尾空白和不安全控制字符均拒绝。
   `sequence` 由本地按数组顺序生成 `1..N`，不让模型自报序号。
2. 用户文案最多 4,000 字符；最多产出 128 句，单句最多 1,000 字符且总脚本文本最多
   4,000 字符。单句上限必须直接复用既有
   `motion_authoring.voiceover.MAX_NARRATION_CHARS`，保证 T1 产物天然可被 T2 的唯一
   TTS 实现消费，不建立第二个旁白长度常量。
3. 模型回复体、结构化正文、请求 ID、token 和超时均有硬上限；只接受
   `finish_reason=stop` 且无非空 refusal 的第一条回复。超时、拒答、截断、空正文、
   畸形 JSON 或任何边界漂移都转换为无异常链的固定
   `ScriptSegmentationRejected("script segmentation request rejected")`，不回显上游正文、
   请求 ID、密钥或本机路径，不自动重试。
4. T1 的完成证据是供应商无关协议、目录选择、默认/开启 thinking、封闭请求与有序结果的
   聚焦自动化；没有用户入口，因此最多是分层证据。真实模型、TTS、PostgreSQL 与正式包
   在 T4 模块收口时统一验收，不在每个小任务重复跑全量。

### 句子对齐算法

1. 对齐前把脚本各句和 ASR 全文做 NFKC + casefold，只保留 Unicode
   Letter/Mark/Number；空规范文本拒绝。全文与逐句均计算带 15% 上限的带状
   Levenshtein 距离，精确相同先走 O(1) 快路；规范长度不超过 4 必须完全一致，其余错误量
   不得超过较长文本的 15%。ASR 全文按最接近原句长度的顺序深度优先搜索连续、非空且
   完整覆盖全文的逐句分区，失败状态缓存，候选检查硬上限 1024 次；每个候选片段长度先受
   同一 15% 门槛约束。每段除满足本句门槛外，还不得同样或更接近另一条不同脚本句子、
   完整取自另一条不同脚本句子。若中间片段可由上一句后缀与下一句前缀组成，则把疑似
   借出的两部分重新分配回左右**实际片段**；替代分配的两侧编辑距离总和不高于当前分配
   时，就按跨边界借字或边界重复插入拒绝。这个总距离判据有意覆盖“一侧变差、另一侧
   等量改善”的歧义，宁可要求用户重录也不把未朗读句子绑定到音频。各候选仍受逐句 15%
   门槛；重叠边界的替代距离用两张增量带状 DP 表一次计算并复用，不按边界重算。候选
   分区仍受 1,024 次硬上限；所有带状 Levenshtein 在构造前按实际长短文本对应的完整
   行分配单元格数累计扣减，单次对齐上限 40,000,000。重叠边界的两张增量表再按
   `实际行数 × (脚本字符数 + 1)` 的完整分配单元格数原子扣减，单次对齐累计上限
   4,000,000；不能再把一次候选或一张大小不等的表都记作相同工作。预算耗尽是独立于
   “距离不匹配”的内部终止状态，必须立即中止整次对齐，不能让否定式唯一性检查把它当成
   “其他句子不匹配”而放行候选。任一预算耗尽即 fail closed。
   固定字符比例不能用：前句出现允许的漏字时会把后句首字符错误划给前句。这只容忍
   标点、空白、大小写、ITN 与少量识别误差，不允许漏句、增句或调换顺序；高歧义输入
   耗尽预算时 fail closed。
2. 时间边界只从 Silero VAD 的真实有序人声区间中选择。人声区间少于脚本句数时，在首次
   ASR 前拒绝，要求用户在句间留下可检测停顿；区间足够时按各句规范字符数对应的累计
   人声时长目标，贪心选择最近且仍给后续每句至少保留一个区间的真实区间边界。每句可
   合并多个相邻人声区间，内部停顿保留；绝不在一个连续人声区间内部猜毫秒切点。
3. 结果逐句携带原 `ScriptSentence`、真实 `source_start_ms/source_end_ms` 和二者差值，
   严格连续 sequence、有序不重叠、全部落在 ffprobe 实测录音时长内；结果另带路径无关
   的完整识别文本并在 `repr` 中隐藏。任一结构漂移统一固定拒绝，不返回部分对齐。
