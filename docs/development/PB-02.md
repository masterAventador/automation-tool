## 交付范围

- 联网复核 B站开放平台当前官方文档（open.bilibili.com 文档集合，正文经官方
  `arcopen/user/open-doc` 目录接口定位后逐篇核对），并把授权、签名、上传、投稿、
  查询、错误码、限流与沙盒锁进版本化契约
  `contracts/publishing/bilibili-open-api.v1.json`：
  - OAuth2：PC/H5 授权页、`/x/account-oauth2/v1/token`、
    `/x/account-oauth2/v1/refresh_token`、grant_type、`expires_in` 为绝对过期时间戳、
    refresh_token 单次使用、过期需重新授权；视频投稿必需 scope 锁定 `ARC_BASE`；
  - 签名 2.0：HMAC-SHA256、六个 `x-bili-*` 签名头、`access-token` 头、时间戳
    10 分钟窗口、空 body MD5 常量；
  - 上传规格：`archive/video/init`（utype 0/1，小文件阈值 100MB）、
    `openupos.bilivideo.com` 分片上传（part_number 从 1 起、分片 8MiB、除最后一片
    等长）、合片、单个小文件上传、4GB/5小时等视频技术边界；
  - 稿件提交：`add-by-utoken` 字段边界（标题 ≤80、简介 ≤250、tag 逗号分隔总长
    ≤200、copyright 1/2 且转载必须带 source、no_reprint 0/1、封面只认封面上传
    返回的 https 地址、tid 只认分区查询结果）、`resource_id` BV 号格式；
  - 查询：`archive/view`、`archive/viewlist`（pn≥1、ps 1..50、status 枚举）、
    已公开的稿件状态取值（0 开放浏览、-2 已退回）；
  - 错误码：官方状态码文档全部通用/OAuth2/鉴权限流/视频稿件错误码逐条分类为
    七个封闭类别，映射到 PB-01 领域语义（invalid_input /
    dependency_unavailable / platform_error），未知非零错误码 fail closed 归入
    platform_error；
  - 旧接口明确拒绝：旧授权页 `passport.bilibili.com/register/pc_oauth2.html`
    （官方声明 2025-03 停止维护）、客户端私有 `passport.bilibili.com/api/v3/oauth2/*`、
    创作中心网页私有 `member.bilibili.com/x/vu/web/add`、第三方镜像文档，以及官方
    示例仓库里的明文 http 端点（本项目 https-only 收紧）。
- 每个契约条目携带官方来源 URL 与核对日期 `2026-07-23`；来源共 18 项（17 篇
  open.bilibili.com 官方文档 + 官方 GitHub 示例仓库 bilibili-openplatform/demo）。
- 新增 57 个脱敏请求/响应 fixture
  `contracts/publishing/fixtures/bilibili-open-api-v1/`，覆盖授权、续期、上传预
  处理、分片、合片、封面、稿件提交、状态查询的合法样例、畸形样例与平台错误样例；
  所有令牌均为 `fixture-` 前缀假值，测试固定断言不得出现真实凭据。

  `backend/src/automation_tool/control_plane/domain/bilibili_open_api.py`：
  封闭 frozen dataclass 契约视图、严格 JSON 装载（顶层键精确匹配、https-only、
  错误码表逐项校验）、响应信封与逐接口解析器、请求字段校验器、分片计划器与

## 失败矩阵

- 契约文档漂移 fail closed：顶层键缺失/多余、版本不符、http 明文端点、空来源、
  必需 scope 不在已知 scope 表、错误码键非规范数字/0/负数、错误类别未声明、
  错误条目多键、空错误表、分片数上限乘分片大小小于视频上限、文件缺失、非 JSON、
  非对象文档全部拒绝装载。
- 响应信封 fail closed：非对象、未知顶层键、code 非 int、message 非 str、ttl 负数、
  request_id 非 str、data 非对象全部拒绝；code≠0 时按错误码表分类，未知非零错误码
  固定归入 `unknown → platform_error`，不猜测语义。
- 成功响应字段 fail closed：token/upload_token/url/resource_id 缺失、类型错、
  带空白、resource_id 非 BV 号、封面 URL 非 https、scopes 含未知项或重复、
  分片/合片确认带 data、稿件详情 addit_info 形状或 state 类型错误全部拒绝。
- 请求侧 fail closed：文件名含路径分隔符/控制字符/无扩展名、utype 非 "0"/"1"、
  part_number 越界（0、513、bool、非 int）、分片计划总大小非正或超 4GB、标题 81 字符、
  简介 251 字符、tag 总长 201 或含空段、copyright 非 1/2、转载缺 source、原创带
  source、no_reprint 非 0/1、封面 http 地址全部拒绝。
- 错误分类映射：documented 错误码逐条锁定七类封闭类别并映射
  invalid_input / dependency_unavailable / platform_error；code 0 与非 int 拒绝进入
  错误分类；契约表中每个错误码都断言能得到 PB-01 领域失败码。
- 凭据卫生：fixture 中所有 access_token/refresh_token/upload_token 字段值必须为
