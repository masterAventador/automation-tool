## 真实边界

- 四类生成图均由本次内置 Image Generation 实际生成，不是 fixture、占位图或上游图片重命名；
  头像明确为虚构人物，提示词禁止真人/名人相似、Logo、商标、文字、水印和受版权保护角色；
  九类材质从同一次原创 3×3 母版按锁定像素裁切，并分别登记生成调用与裁切坐标。
- 生成输出权利不是伪造的开源许可证。台账按 2026-07-23 核对的 OpenAI Terms of Use /
  Services Agreement（均自 2026-01-01 生效）记录“在适用法律允许范围内，用户/客户与 OpenAI
  之间由用户/客户拥有 Output”，同时明确输出可能不唯一、项目仍负责第三方权利审核且不构成
  不侵权保证。
- 音频、SVG/UI、地图、GLB 和本地脚本由构建器自研产生；字体逐字节复用 BM-12 从 Google
  Fonts 锁定并核验的 Big Shoulders Display latin WOFF2，SHA-256
  `203dd8ba4ae61b19cd2e00c66708f0d0f6d8484cdfdb1d7e8be37260d36a99b1`。
- 68 指的是“含商标指示词的目录项数”；一个目录项可含多个词，因此台账实际有 121 个
  item/indicator 关系。内部目录 ID 可保留上游词供代码寻址，替换目标内容与提交资产不含这些词；
  UI 是否完全隐藏仍由既有用户品牌扫描和 BM-14～BM-16 最终目录/页面门禁复验。
- `generated-illustration` 是明确标注 `libraryOnly` 的原创母版，供 BM-14/BM-15 作为通用插画
  选择；其余 43 份资产均被至少一个示例素材引用直接消费。
- `vendor/hyperframes` 和 `vendor/moneyprinterturbo` 始终保持锁定 commit 与干净工作树；所有
  变更只在 App 自有 `assets/`、`contracts/`、`scripts/` 和文档中。
