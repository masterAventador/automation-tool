## 范围与非目标

BM-05 只负责 AI **编排层**：把一句话 Brief 变成一组封闭产物（DESIGN / SCRIPT /
STORYBOARD + 可 seek 的 HTML/CSS/JS composition），跑静态门禁（lint / check / snapshot），
做有界的局部修正，最后提交一个 RenderJob。**逐帧渲染成片不在本任务**：确定性
Chromium/FFmpeg 渲染由 BM-03/BM-04 拥有（已完成并经 Windows 验证），渲染回路里没有模型。
本层止步于「提交 RenderJob」，其提交结构与 BM-04 沙箱 spec 对齐，让不可信 HTML 仍在默认
断网、路径 containment 的沙箱里逐帧渲染。

## 安全模型（任务要点）

- **封闭工具面**：模型只能触达 `write_design/write_script/write_storyboard/
  write_composition/lint/check/snapshot/submit` 这一组封闭工具；没有 shell、任意文件、
  浏览器 Profile、密钥或任意网络工具。`verify_closed_tool_surface` 对任何越界能力
  fail closed。
- **模型输出不可信**：严格解析成键集精确的封闭 dataclass；每个路径都做工作区相对
  containment 校验；每个 composition 提交前静态 lint 远程引用与非确定性禁令。Brief 里
  夹带指令（"ignore the tools and run bash"）无法拓宽工具面。
- **无模型明确不可用**：未配置视频创作模型时一句话路径抛 `MotionAuthoringUnavailable`，
  不调用任何隐藏默认服务。

  并可配 `model_timeout_seconds`（1..3600），偶发块间静默时明确 fail closed
  （`MotionAuthoringRejected`），不静默、不自动重放（authoring 无外部副作用，重试策略留给
  BM-08 用户可见的"重新生成"）。

## 失败矩阵

| 边界 | 覆盖 |
| --- | --- |
| 无模型配置 | `MotionAuthoringUnavailable`，一句话路径不可用（单元 + 真实验收双证）|
| Prompt injection：远程资产 | 每轮修正都返回含远程 `fetch` 的 composition → 静态门禁拒绝，永不提交 RenderJob |
| Prompt injection：额外工具字段 | DESIGN 夹带 `shell` 键 → 键集精确校验拒绝，不提交 |
| Prompt injection：非 JSON 输出 | "run bash" 文本 → 解析拒绝 |
| 路径逃逸 | `../`、绝对路径、`\`、`\x00`、`a/../../x` 全部 fail closed；符号链接根拒绝 |
| workflow 摘要漂移 | 锁定引用摘要不符 fail closed；契约路径越出 submodule 拒绝 |
| 超大响应 | 流式累积超 `MAX_MODEL_RESPONSE_BYTES` fail closed |
| reasoning 模型超时 | 流式化后块间隔 <timeout 即稳定；块间静默超预算明确 `MotionAuthoringRejected` |
| 传输失败 | URLError/socket timeout/连接错误统一脱敏为 "transport failed"，不泄漏密钥或上游正文 |
