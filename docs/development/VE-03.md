## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| DTO 出现 provider/region/api key 等供应商字段或未知字段 | strict schema 与精确字段测试拒绝 |
| 修订号非正整数、总时长超出 0.1–600 秒、无画面轨道、轨道/片段 ID 重复 | Zod 校验拒绝 |
| 片段重叠或越过总时长、字幕片段带素材、画面/音频片段带文字 | Zod 校验拒绝 |
| 转场时长超出 1–10000 毫秒或类型未知 | Zod 校验拒绝 |
| 画面/音频片段缺素材引用、字幕缺文字、时长非法时保存 | 网关拒绝并提示“时间轴还不完整”，不产生修订 |
| 项目标题为空/全空白/超长、素材引用非法或重复 | 网关拒绝并给出中文提示 |
| 本机草稿数据损坏 | fail-closed，显示“本机剪辑草稿暂时无法读取”，不渲染空列表冒充正常 |
| 云端剪辑链路未建成时提交 | 固定 `editing_service_unavailable`，显示“云端剪辑功能尚未开通”，任务列表保持为空 |
| 页面出现上游项目名、供应商名或假结果文案 | 组件测试与桌面验收扫描均失败 |
| EditingJob 状态与输出/失败码事实不一致 | schema 拒绝（与领域状态机语义一致） |

## 正常用户路径验收

验收构建使用生产 `main.tsx` 和正式 `WorkbenchShell`，复用 VF-06 隐藏隔离 App、隔离
identifier 与动态空闲 WebDriver 端口。用户路径为：

1. App 正常进入“RPA 运营工作台”，确认左侧同时存在“视频制作”和独立的“视频剪辑”；
2. 点击“视频剪辑”，标题变为“视频剪辑”，剪辑项目页显示真实空状态；
3. 填写标题与素材引用创建剪辑项目，核对“已创建剪辑项目”提示与项目列表；
4. 打开时间轴编辑，确认默认画面轨道已带入项目素材；添加字幕轨道并输入字幕文字，
   为画面片段选择“淡入淡出”转场；
5. 连续保存两次，核对“已保存修订：第 1 版 / 第 2 版”单调递增；
6. 打开预览，核对轨道/片段结构与“视频画面预览将在云端剪辑服务接入后提供”说明；
7. 打开提交与任务，点击“提交剪辑任务”，核对“云端剪辑功能尚未开通”的真实不可用状态，
   任务列表保持“还没有剪辑任务”；
8. 整页扫描确认没有上游项目名、供应商名称和假结果文案。

该路径操作的是正式 App 左侧入口和生产组件，最终状态由真实 DOM 文本与本机草稿存储
确认，不是网页预览、Mock 或测试专用入口。

## 真实边界

- VE-03 只交付剪辑工作台前端与本机草稿：项目与时间轴修订保存在 App 会话的
  sessionStorage，App 重启后不保留；服务端持久化与真实提交由 VE-04～VE-07 接入
  阿里云 IMS/ICE 链路后提供。
- “提交剪辑任务”当前必然失败为“功能尚未开通”，没有任何任务会被创建；任务详情
  骨架只在网关返回真实任务时渲染（本任务内仅作为分层组件证据）。
- 预览是时间轴结构文字预览，不渲染视频画面，页面已如实说明。
- 时间轴编辑为表单/列表式，不含可视化拖拽；片段起止时间自动顺排，暂不支持留空隙。

## 清理
