- 权限：migrator 独占 schema/DDL 与 Alembic；app 只有既有及未来表的 DML、序列和必要函数执行；backup 只有表/序列 SELECT。`PUBLIC` 的数据库/schema 创建能力被撤销，不授予内建全库读写角色
- 镜像：Control Plane 镜像包含只读 Alembic 配置和迁移资产，但生产入口不自动迁移；一次性迁移作业必须显式覆盖 entrypoint，使用 migrator Secret 串行执行
- 真实验收：唯一私网中启动 primary 与全新 restore 两个 PostgreSQL 18 实例，均无宿主端口；正式 Alembic 全链由 migrator 跑到 head，app DML 成功而 DDL 拒绝，backup SELECT 成功而 INSERT 拒绝；backup role 生成 `--no-owner --no-acl` custom dump，恢复到第二实例后 Alembic revision 和两条探针数据精确一致
- Secret/备份边界：密码只在 `0600` `.local/automation-tool-c10-03-*` 临时 Secret 文件和进程 stdin 出现，不进入 argv、Git、SQL、镜像或日志；备份文件 `0600`，真实云环境必须进入供应商加密存储并按 C10-01 保留 7 天
