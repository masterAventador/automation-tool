  - `EmbeddedBrowserDistribution::load(_for_target)` 只从 Tauri resource 目录解析
    `embedded-browser/` 发行物：resource 根与发行物根拒绝 symlink/reparse、必须为

    Manifest 显式声明且目标解析后仍在发行物根内**（未声明链接、目标漂移、绝对/

## 失败矩阵

- resource 根或发行物根被 symlink 替换、非直接子目录：拒绝（专项测试）；
- Manifest 缺失、超界、schema 漂移、未知字段、identity/版本漂移：拒绝；
- 文件被篡改（摘要）、大小不符、缺失、多余：拒绝；
- 未声明 symlink、声明目标漂移、绝对/逃逸目标：拒绝；
- 第二浏览器命名（chrome-headless-shell 等）：拒绝；
- 平台错配（windows 目标在 mac 树上）与未知目标：拒绝；
- 特殊文件类型（非文件/目录/声明链接）：拒绝；
- 全部拒绝路径为固定消息，不反射树内容或用户路径。
