## 交付范围

- 新增阿里 Adapter 私有模块 `backend/src/automation_tool/control_plane/domain/aliyun_ims_editing_provider.py`：
  - **Timeline 编译器** `compile_aliyun_timeline`：把内部 `EditingTimeline`（VISUAL/AUDIO/CAPTION
    轨道、片段、转场）编译成官方 `SubmitMediaProducingJob` 的 Timeline JSON
    （VideoTracks/AudioTracks/SubtitleTracks，字幕用 `Type=Text` 横幅字，图片素材按官方要求
    输出 `Type=Image + Duration`，时间统一按官方文档换算为秒）。编译是纯函数：同输入产出
    逐字节相同的规范化 JSON。
  - **能力差异提交前显式拒绝**（映射 Provider 封闭错误分类，不静默降级）：内部 `DISSOLVE`
    转场在官方普通转场清单中没有等价项 → `unsupported_capability`；转场落在轨道第一个片段
    （官方转场只放在前一个片段的 Effects 中，无前片段不可表达）→ `unsupported_capability`；
    音频/字幕片段带非 CUT 转场 → `unsupported_capability`；`FADE→fade`、`WIPE→wiperight`、
    `CUT→不产生 Effect`。素材扩展名与轨道类型不符、staging 计划缺素材键 → `invalid_input`。
  - **提交编排** `AliyunImsEditingProvider.submit`：消费 VE-04 的 `EditingServicePreflight`
    （任一检查非 PASSED 即拒绝，不提交）与 `MediaStagingPlan`（同地域、摘要去重对象键）；
    先持久化 prepared 意图（请求哈希，含 timeline 内容、修订、身份与输出配置的 SHA-256），
    单次 dispatch，成功后持久化 DISPATCHED 状态与真实 JobId；`ClientToken` 使用领域幂等键。
  - **一次提交语义对齐副作用规则**：响应丢失/超时/5xx → 记 UNCERTAIN 并返回
    `outcome_uncertain` 快照，重放**不再重发**；请求确未发出（连接失败）→ 意图保持 PREPARED，
    允许重试；同幂等键不同内容 → `conflict`；重放同内容 → 返回原快照且不再调网络。
  - `AliyunEditingIntent`（PREPARED/DISPATCHED/UNCERTAIN 封闭状态不变量）、意图存储 Port 与
    进程内参考实现、`AliyunImsSubmitTransport`/`AliyunMediaStagingPlanner`/
    `AliyunEditingPreflightSource` Port、封闭传输失败分类（`rejected_*` 仅允许在网关确定未建任务
    时使用，歧义一律 `response_lost`）。
  - **ACS3-HMAC-SHA256 签名纯函数** `acs3_signed_headers` 与 RFC3986 规范化查询串，供
    Control Plane 侧真实调用使用（与 VE-04 Rust 实现同一官方算法）。
  - `get`/`cancel`/`fetch_artifacts` 按 VE-02 契约实现（本地意图状态推进 +
    `EditingJobStateMachine` 合法转换）；`record_running`/`record_succeeded`/`record_failed`
    是 VE-06 回调/轮询对账的入口，本任务不做轮询与对账。

## 失败矩阵

- 编译：DISSOLVE/首片段转场/非视觉轨转场 → `unsupported_capability`（提交前拒绝，无副作用）；
  staging 计划缺键、扩展名与轨道类型不符、跨地域计划 → `invalid_input`；错误消息固定，不含
  bucket、对象键、摘要或用户内容。
- 提交：preflight 任一 FAILED/UNVERIFIED → `dependency_unavailable` 且不落任何意图、不调网络；
  不支持的 Timeline → 拒绝且无副作用（get 仍 `not_found`）。
- 传输：连接失败（确未发出）→ `dependency_unavailable`，意图保持 PREPARED，允许重试且重试后
  仅一次有效建任务；响应丢失/超时/5xx → UNCERTAIN + `outcome_uncertain`，重放不重发；
  400 → `invalid_input`；403 → `dependency_unavailable`；429 → `dependency_unavailable`。
- 幂等：同键同内容重放返回原结果（含 UNCERTAIN 快照）；同键不同内容（含仅修订变化）→
  `conflict`；请求哈希绑定 Timeline 内容、修订、工程/任务身份与输出配置。
- 意图不变量：非 64 位小写 hex 哈希、PREPARED 带 JobId、DISPATCHED 无 JobId、UNCERTAIN 带
  非 uncertain 状态、SUCCEEDED 无输出、FAILED 无失败码等一律构造即拒绝。
- 对账入口：非法状态机转换（如 QUEUED 直接 SUCCEEDED）→ `conflict`。
- VE-02 契约套件：取消协作式、终态取消保持原结果、未知任务 `not_found`、
  `fetch_artifacts` 未确认成功 `conflict` 等对新 Adapter 全部通过。
