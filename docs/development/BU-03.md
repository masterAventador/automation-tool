## 交付范围

- 新增受限工具面 `tools/browser-use-contract/browser_use_restricted_tools.py`
  （位于 BU-01 锁定的 browser-use==0.13.6 隔离环境工程内）：
  - 封闭动作分区：上游 24 个默认动作被完整划分为 16 个允许
    （观察类 extract/find_elements/find_text/search_page/screenshot/wait/
    dropdown_options、同域导航 navigate/go_back、click、input/send_keys、
    select_dropdown、scroll、受控 upload_file、结构化终止 done）与 8 个禁止
    （任意 JS `evaluate`、文件 `read_file`/`write_file`/`replace_file`、下载
    `save_as_pdf`、跨域搜索 `search`、标签管理 `close`/`switch`）；Shell 类动作
    上游不存在，分区校验保证未来新增默认动作立即 fail closed；
  - `create_restricted_tools()` 用 `Tools(exclude_actions=…)` 构建后强制
    `verify_restricted_registry`：注册面必须精确等于白名单，漂移（多一个或
    少一个）一律拒绝；
  - `RestrictedAgentPolicy`：非空 https-only 域白名单（支持 `*.` 通配）、可选
    路由前缀白名单（绝对、干净路径）、步骤上限（≤50）、单步动作上限（≤5）、
    单步时长上限（≤300s）全部硬边界校验；`is_url_allowed` 组合域+路由判定
    （拒绝 http、凭据注入、端口、宿主伪装如 `douyin.com.evil.com`）；
  - `restricted_agent_kwargs` / `restricted_run_kwargs`：把策略映射为上游
    Agent 构造与 `Agent.run` 的受限关键字。
- 新增确定性测试 `scripts/test_browser_use_restricted_tools.py`（12 项，真实
  库、零浏览器零网络）与验收入口 `scripts/run_bu_03_acceptance.py`。

## 失败矩阵

- 上游默认动作漂移（新增/移除）：分区校验与注册面校验双重 fail closed；
- 注册面被运行时篡改（注入新动作/摘除允许动作）：`verify_restricted_registry` 拒绝；
- 域白名单：空、非 https、裸域名、带路径、file://、`https://*` 全拒绝；
- 路由前缀：相对路径、`..`、空串、非法字符全拒绝；
- URL 判定：http、宿主伪装、凭据/端口注入、非白名单路由、非法 URL 全部 False；
- 步骤/单步动作/时长越界（0 或超上限）全拒绝。
