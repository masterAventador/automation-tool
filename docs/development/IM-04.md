## 失败矩阵

- 来源 Provider、目标适配器、Base URL、用途、模型、密钥格式或字段集合漂移：启动前拒绝。
- 未配置文案服务、损坏秘密存储、用途错误或旧模型：只返回固定配置错误，不启动降级 Provider。
- Worker bootstrap 缺失、多余、重复或含任意地址/模型：固定拒绝，不监听端口。
- 未安装适配器、响应缺少文本或请求异常：只返回固定错误，不反射密钥、URL 或服务端正文。
- Debug、公开状态和序列化结果不得出现测试密钥、百炼 Base URL 或原始 localhost 地址。
- 候选目录出现 `config.toml`，或适配过程导入上游配置模块：验收失败。
