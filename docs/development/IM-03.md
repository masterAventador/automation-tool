## 失败矩阵

- 相对、缺失、符号链接或 reparse point 素材根目录，以及可执行路径异常：启动前拒绝。
- bootstrap 字段缺失、多余、重复、协议/Worker 类型错误、令牌长度错误或超限：固定失败且不监听。
- 无认证、重复认证头、错误来源、通配来源、未知路由、查询串、非法请求 ID：固定状态和错误体。
- 流式请求、缺失/重复/超限 Content-Length、错误 Content-Type、畸形或重复 JSON 字段：拒绝。
- 绝对路径、`..`、反斜杠、缺失文件、目录、符号链接、空文件、超限文件和根目录外目标：拒绝。
- ready、health 或 cancel 的事件、版本、端口、任务 ID、类型或 HMAC 证明不匹配：Rust 侧拒绝。
