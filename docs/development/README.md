# 独立任务记录

本目录按任务 ID 保存执行证据，每个任务固定使用一个 `docs/development/<任务ID>.md` 文件。`development-roadmap.md` 只维护任务定义、依赖、状态和当前下一步，不再追加完成记录。

会话恢复时只读取路线图和当前任务文件，不批量读取本目录中的历史记录。

每个任务文件至少记录：

- 状态、日期和提交；
- RED 失败测试与原因；
- GREEN 验证命令与结果；
- 真实平台或运行边界；
- 用户可操作功能的正式 App 正常用户路径验收，或纯文档/治理任务的不适用原因；
- 失败矩阵；
- 资源清理；
- 同步文档；
- 遗留项。
