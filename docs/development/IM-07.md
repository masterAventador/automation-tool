## 失败矩阵

| 场景 | 结果 |
| --- | --- |
| 未打开制作界面或尚无任务 | 返回空列表，不制造示例任务 |
| observation 多字段、超限、路径、错误 UUID/状态事实 | fail closed 为 `job_unavailable` |
| 旧修订或重复完成通知 | 保留当前检查点，Artifact 只导入一次 |
| 并发第二个上游任务 | Worker 拒绝，不覆盖第一个任务 |
| 输出在任务目录外、软链接或非 MP4 | Worker 拒绝，不复制也不导入 |
| 取消标记被替换成目录/链接 | Tauri 拒绝，不跟随链接 |
| Worker 直接删除任务 | 明确拒绝；保留和删除只由 App 执行 |
| 状态读取或操作失败 | App 显示可理解提示，不伪造成功状态 |
