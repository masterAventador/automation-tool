checkpoint 可在 App 重启后恢复；路径越界、链接替换、磁盘空间不足、重复/非法名称和
工作区 identity 替换全部拒绝。

## GREEN

- Tauri 正式组合根持有唯一 `VideoJobWorkspaceStore`；每个 RenderJob UUIDv4 对应稳定
  identity 的私有 `outputs/checkpoints/work`，Worker 输出目录每次取得前重新校验。
- checkpoint 使用 0600 临时文件、fsync、原子替换和目录同步；同名保存安全覆盖，数量、
  单项大小、任务总量和最低剩余空间均在写入前检查，重启后可以恢复。
- 输出只接受单段安全文件名、固定媒体类型/角色；导入使用 1 MiB 缓冲流式复制并计算
  SHA-256，payload + 无路径 manifest 在临时私有目录完成后以一次 rename 原子发布。
- Artifact 通过稳定 UUIDv4、Job ID、摘要、大小、媒体类型和角色对账；读取先流式复验
  摘要再返回有剩余字节上限的 Reader，不把最高 32 GiB 内容整体读入内存。
- `Keep` 固定保留截止时间，过期清理只删除到期且整树复验无链接的工作区；`Delete`
  立即删除工作区，已导入 Artifact 独立保留并只按 Artifact ID 显式删除。
- 8 项 VF-03 真实文件系统测试、严格 Clippy/Rustfmt 和 Tauri crate 全量 218 项通过
  （4 项既有环境型测试按约定 ignored）。

## 失败矩阵

- 非 UUIDv4 Job、重复创建、缺失或被 rename 后同名替换的工作区全部拒绝，错误不反射
  AppData 路径。
- 相对越界、绝对路径、多段名称、symlink/reparse、普通文件替代目录，以及删除前目录树
  中的未知特殊节点全部拒绝。
- 单 Artifact/单任务配额、checkpoint 数量与 1 MiB 上限、最低剩余空间加本次写入量的
  溢出/不足都在创建部分文件前失败；失败后 inventory/checkpoint 目录保持无残片。
- 导入前后复验源文件 identity/大小；同大小 payload 篡改在消费前由 SHA-256 拒绝；
  重启只清理严格匹配协议名称和安全目录结构的 `.import-*` 中断目录。
- 用更严格 policy 重开时，旧 Artifact 超过新上限会让 Store fail closed；不会因已有
  manifest 绕过当前额度。
- 活跃 Job 没有保留截止标记时不被过期清理；到期 Keep、明确 Delete、重启恢复和
  Artifact 独立存续均有真实磁盘断言。

## 正常用户路径验收

不适用。VF-03 是视频制作正式页面和两类 Worker 后续消费的 Tauri 本机存储底座，本任务
不新增用户入口。

## 真实边界

测试使用真实私有临时目录、真实文件描述符、流式复制/fsync/rename 和 `statvfs` 实际
可用空间查询；Windows 路径实现固定使用 reparse 属性、`GetDiskFreeSpaceExW` 和
write-through 原子替换，但 Windows 正式包仍由后续双平台任务验收。本任务不生成视频、
不调用模型、上游项目或云服务。

## 清理

和 panic 路径递归回收；没有固定端口、进程、容器、数据库或本地服务。
