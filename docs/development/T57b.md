## C3 / T25 前置资源证据

视频族迁移到 `control-plane-e2e` 后，八个 runner 仍统一包在
`video_studio_startup_harness()` 中。它会：

- 调用 `prepare_startup_gate()`，安装签名 executor
  （`scripts/desktop_e2e_prerequisites.py:484-503`）；executor cache 不存在时会
  由 `ensure_signed_executor_package()` 构建，因此不需要独立 prerequisite；
- 为每次调用创建受管 PostgreSQL、执行 Alembic，并启动/回收生产 Control Plane
  （`scripts/desktop_e2e_prerequisites.py:603-631`），不需要独立 prerequisite；
- BM-08 / IM-05 所需的专属视频 runtime 由各自 runner 产生并安装，见上一节，
  不需要独立 prerequisite。

但 embedded browser 是例外。`stage_embedded_browser()` 只消费
`.local/desktop-e2e/embedded-browser/<target>` 的现成 cache，manifest 不存在就
直接拒绝（`scripts/desktop_e2e_prerequisites.py:298-322`）；runner 和 harness
不会调用 `build_embedded_browser_cache()`。仓库已有可复用 producer：

```text
python3 scripts/desktop_e2e_prerequisites.py
```

其 `main()` 会从本机已锁定的 Chromium archive 构建并验证 cache
（`scripts/desktop_e2e_prerequisites.py:756-760`），archive 缺失时在
`:255-261` fail closed，且不会偷偷下载。因此 C3/T25 需要一个目标平台感知的
独立声明。并行 C3 已按这份证据加入 `video-e2e-embedded-browser`：路径从真实
harness helper 派生（`scripts/gate_prerequisites.py:118-128`），producer
指向上述现成命令（`:203-224`）。本子任务没有修改该脚本，避免并行写面冲突。

B5-04 不应通过新增 prerequisite 延长寿命；H8-20/H8-21 的 TLS 服务、feed、
certificate 和临时缓存均由 runner 本次调用产生，也不需要新增持久资源声明。

迁移后 harness 仍通过 `startup_gate_environment(..., control_plane_port=8765)`
把同一 origin 编进 `control-plane-e2e` build，运行语义没有变化；但
`scripts/desktop_e2e_prerequisites.py:563-574` 的 docstring/错误文案仍把原因
写成“`video-studio-e2e` feature 固定 8765”。该脚本属于并行 C3 写面，本子任务
没有抢写；后续应只更新说明，不能删除 8765 的独占/清理边界。
