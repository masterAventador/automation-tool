## 真实包上的验收（2026-07-27 晚补）

改版随签名公证的客户 Demo 包出厂，产品负责人打开它走了真实用户路径。**这一步暴露了
UI Harness 全绿也发现不了的一条布局缺陷**，记在这里，因为它正是本条声明要求的终态证据：

```
包           自动化运营工具_0.1.0.dmg  495,121,035 字节
             Notarized Developer ID，DMG 与卷内 .app 票据均通过
现象         左侧菜单跟着右侧内容一起滚动；AI 助理的输入框被截在窗口外
实测         document.scrollHeight - clientHeight = 52px
             1280×800 与 960×640 两个尺寸完全一致
```

根因不是改版本身写错，而是它继承的 `.desktop-shell { height: 100vh }` 在客户 Demo
Profile 下不再成立——`AccountSessionGate` 在外壳之上加了一条约 52px 的账号栏。
`.assistant-home` 的 `calc(100vh - 64px)` 是同一个病根的第二处。

修复见提交 `8eae4e7`：两处都改为由布局计算而非硬编码常数。同时补上
`frontend/e2e/account-shell-layout.spec.ts` 与 harness 的 `?account=signed-in` 场景——
**此前 Harness 从不挂账号门，所以 e2e 量的页面比客户打开的矮 52px，断言全过而包是坏的。**

修复后：Playwright 78 passed（含新增 6 条，先跑到 2 红再转绿）、Vitest 588 passed、
契约 264 passed、tsc 与 eslint 均 0。

**仍差**：改版其余页面（热点发现、创作、发布、消息与互动、自动化）在真实 Tauri 窗口
里的逐页走查，故状态保持 `🔍`。

## 目标

在不改变既有后端、IPC、RPA 和平台能力边界的前提下，重做桌面 App 的信息架构与主要页面，
让 AI 助理成为默认入口，同时保留用户手动进入热点、创作、发布、消息、自动化、账号和设置
的路径。所有视频制作与剪辑页面必须嵌入同一个 App 工作区，不允许再从正式入口打开第二窗口。

## 已确认的产品范围

- 产品服务短视频运营人员；长期方向是用户通过一个持续主会话让 AI 串联全部工作。
- 默认进入 AI 助理，只维护一个长期主会话。
- 主导航固定为：AI 助理、热点发现、创作、发布、消息与互动、自动化；账号与平台、设置置底。
- 热点由关键词驱动，最快 20 分钟扫描，高潜内容立即提醒，普通摘要每小时汇总。
- 发布必须由用户确认，并在真正发布前再次确认。
- 普通评论和私信默认由 AI 回复，风险内容转人工；每条消息必须标记来源平台。
- 每个平台首期只连接一个账号；暂不做多品牌。
- 智能素材成片、品牌动效成片和视频剪辑全部在 App 内工作，不弹额外窗口。

## RED

先新增 `WorkbenchShell.redesign.test.tsx`，以四条契约固定：

1. 默认 AI 首页和新导航；
2. 长期主会话可发送消息；
3. 热点关键词能切换结果；
4. 每条消息包含来源平台。

首轮因旧工作台仍以“工作台/任务”为默认入口而失败。实现后，视觉验收又通过失败测试暴露：

- 正式内嵌制作路径仍显示“打开完整制作界面”；
- 制作与剪辑在 `1280 × 800` 下因重复标题和说明产生约 200 px 额外滚动。

两项均先保留失败证据，再修正生产代码。

## 失败矩阵

- API 未接：页面明确显示待接入或演示数据，不伪造真实返回。
- 外部窗口：内嵌正式入口不暴露外部窗口按钮，自动化测试固定该契约。
- 低屏效：进入制作/剪辑后切换为专注工作区，密度测试约束滚动高度。
- 平台来源丢失：消息列表 accessible name 与详情均断言平台来源。
- 人工接管：聚焦回复框立即改变状态，并提供“交还给 AI”。
- 发布误触：发布前显示目标、时间、平台和再次确认文案。
- 小视口：导航、消息列表和详情在 `1100 × 780` 下保持可用。

## 真实边界与遗留

- 本轮完成的是 React UI 改版，不是平台功能接入。
- UI Harness 不能证明 Tauri IPC、原生窗口、RPA、真实平台账号或第三方视频服务已经工作。
- 热点页等待接入用户提供的 `af.xuanbai.tech` 关键词接口。
- 平台消息读取、AI 回复、自动发布、微信好友与聊天自动化仍依赖后续真实能力任务。
- 视频制作/剪辑已完成 App 内信息架构和入口，但底层未接通的服务继续如实标注。
- 真实 Tauri 窗口还需在可用的本地服务与桌面运行环境中逐页复验，因此任务保持 `🔍`。
