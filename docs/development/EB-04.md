## 失败矩阵

- 未知/不可构建目标、归档缺失或 SHA-256 不一致：解压前拒绝；
- 路径穿越、绝对路径、额外根、重复条目、禁止第二浏览器：安全解压拒绝；
- Windows 目标出现 symlink：不尝试创建 reparse point，直接 fail closed；
- `chrome.exe` 缺失、非 PE、PE 签名错误或 machine 不是 x86_64：启动前拒绝；
- 两次 Manifest 不一致、完整浏览器规模不足、离线启动版本漂移或进程残留：验收失败。
